🛠️ How to Use This Repository  

1. **Install Obsidian** – the markdown‑based knowledge‑base editor.  
   - Download the latest version from the official site: <https://obsidian.md/>  
   - Follow the installation instructions for your OS (Windows, macOS, Linux).  

2. **Clone (or download) the repository**  

   ```bash
   # Using HTTPS
   git clone https://github.com/<your‑username>/network‑knowledge‑base.git
   # OR using SSH
   git clone git@github.com:<your‑username>/network‑knowledge‑base.git
   ```

   *(Replace `<your‑username>` with your GitHub/GitLab account name.)*  

3. **Open the folder in Obsidian**  

   - Launch Obsidian.  
   - Click **“Open folder as vault”** on the start screen.  
   - Navigate to the folder you just cloned (`network‑knowledge‑base`) and select it.  

   The vault will load all markdown files, allowing you to:  

   - Browse the **theoretical notes** in `Networks/` and `Python/`.  
   - Run or examine the **automation scripts** in `Scripts/`.  
   - View the **cheat‑sheets** in `NetCheatSheets/` (click on any image to enlarge).  

4. **(Optional) Install Python dependencies** – if you plan to execute the scripts locally.  

   ```bash
   cd network-knowledge-base/Scripts
   python3 -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   pip install -r requirements.txt   # create this file as you add libs
   ```

   After that you can run any script, e.g.:

   ```bash
   python get_interface_status.py --host 10.0.0.1 --user admin --password secret
   ```
