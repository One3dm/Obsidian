## 📄 **Cisco IOS (Internetwork Operating System)**

**Tags:** #Networks #Cisco #IOS

---

**Cisco IOS** — базовая операционная система большинства маршрутизаторов и коммутаторов Cisco.

---

### 🧠 Где хранится и как работает?

| Компонент | Что хранит | Энергозависимость |
|-----------|------------|-------------------|
| **Flash** | Файл IOS (образ ОС) | Нет (данные не теряются) |
| **RAM (ОЗУ)** | Запущенная IOS, таблицы маршрутизации, ARP, кэш | Да (теряется при отключении питания) |
| **NVRAM** | Файл конфигурации (startup-config) | Нет |

**Цикл загрузки:**
1. Устройство включается
2. IOS копируется из Flash → в RAM
3. Запускается из RAM (для производительности)
4. Конфигурация загружается из NVRAM

---

### 🔄 Режимы загрузки IOS

| Режим | Описание | Когда используется |
|-------|----------|-------------------|
| **ROMMON** (ROM Monitor) | Базовый режим, минимальная загрузка | Восстановление пароля, загрузка через TFTP, сбой образа |
| **RXBOOT** | Загружает урезанный образ IOS из Flash | Обновление IOS, диагностика |
| **Normal Boot** | Полноценная загрузка IOS из Flash в RAM | Обычная работа |

> [!warning] Если образ IOS повреждён или не найден — устройство уходит в ROMMON. Там доступны только базовые команды: `set`, `unset`, `boot`, `reset`.

### ⬆️ Обновление IOS (практика)

**Зачем обновлять:**
- Исправление уязвимостей
- Новые функции (Feature Sets)
- Баг-фиксы

**Порядок действий:**

1. **Скачать образ** с сайта Cisco (требуется контракт поддержки)
2. **Запомнить MD5-сумму** с сайта Cisco для проверки целостности
3. Скопировать образ в Flash:
   ```cisco
   copy tftp: flash:
   ```
   Или через FTP:
   ```cisco
   copy ftp: flash:
   ```
3. **Проверить MD5 образа на устройстве** (обязательно!):
   ```cisco
   verify /md5 flash:<имя_файла.bin>
   ```
   > [!warning] Сравни полученную MD5 с той, что указана на сайте Cisco. Если не совпадают — файл повреждён, не используй его!

4. **Изменить загрузочную переменную** (указать, какой образ грузить):
   ```cisco
   boot system flash:<имя_файла.bin>
   ```
5. **Сохранить конфигурацию и перезагрузиться:**
   ```cisco
   write memory
   reload
   ```
6. **Проверить версию после загрузки:**
   ```cisco
   show version
   ```

> [!tip] Перед обновлением всегда делай бэкап текущей конфигурации и образа!

Версии IOS

Формат: **a.b(c.d)e**

| Часть | Что значит |
|-------|-------------|
| a | Основная версия |
| b | Младшая версия |
| c | Номер релиза |
| d | Номер сборки (rebuild) |
| e | Тип выпуска (T — Technology, E — Enterprise, S — Service Provider) |

**Типы выпусков:**
- **ED** — Early Deployment (новые функции)
- **GD** — General Deployment (стабильная, рекомендована)
- **MD** — Maintenance Deployment (исправления и поддержка)

---

Feature Sets (наборы функций)

| Набор | Что добавляет |
|-------|---------------|
| **IP Base** | База (статическая маршрутизация, OSPF, EIGRP, BGP, Multicast) |
| **Data** | MPLS, BFD, IP SLA |
| **Unified Communications** | Голос (CUBE, SRST, Voice Gateway) |
| **Security** | Firewall, VPN, IPS, DMVPN |


Исключения (не IOS)
- **ASA** — Linux
- **IOS-XR** — для операторских роутеров
- **NX-OS** — для дата-центровых коммутаторов (Nexus)


Способы управления IOS
- Консоль (Console)
- Telnet / SSH
- AUX-порт
