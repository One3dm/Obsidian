Cisco IOS (Internetwork Operating System)

**Cisco IOS** — базовая операционная система большинства маршрутизаторов и коммутаторов Cisco.

| Компонент     | Что хранит                                      | Энергозависимость                    |
| ------------- | ----------------------------------------------- | ------------------------------------ |
| **Flash**     | Файл IOS (образ ОС)                             | Нет (данные не теряются)             |
| **RAM (ОЗУ)** | Запущенная IOS, таблицы маршрутизации, ARP, кэш | Да (теряется при отключении питания) |
| **NVRAM**     | Файл конфигурации (startup-config)              | Нет                                  |

**Цикл загрузки:**
1. Устройство включается
2. IOS копируется из Flash → в RAM
3. Запускается из RAM (для производительности)

Версии IOS

Формат: **a.b(c.d)e**

| Часть | Что значит |
|-------|-------------|
| a | Основная версия |
| b | Младшая версия |
| c | Номер релиза |
| d | Номер сборки (rebuild) |
| e | Тип выпуска (T — Technology, E — Enterprise, S — Service Provider) |

**Типы выпусков:**
- **ED** — Early Deployment (новые функции)
- **GD** — General Deployment (стабильная, рекомендована)
- **MD** — Maintenance Deployment (исправления и поддержка)

Feature Sets (наборы функций)

| Набор | Что добавляет |
|-------|---------------|
| **IP Base** | База (статическая маршрутизация, OSPF, EIGRP, BGP, Multicast) |
| **Data** | MPLS, BFD, IP SLA |
| **Unified Communications** | Голос (CUBE, SRST, Voice Gateway) |
| **Security** | Firewall, VPN, IPS, DMVPN |

Исключения (не IOS)

- **ASA** — Linux
- **IOS-XR** — для операторских роутеров
- **NX-OS** — для дата-центровых коммутаторов (Nexus)

Способы управления IOS

- Консоль (Console)
- Telnet / SSH
- AUX-порт
