VLAN (Virtual Local Area Network)

VLAN (Virtual Local Area Network) — это способ логического разделения сети на отдельные изолированные сегменты, независимо от физического подключения устройств.


Простыми словами: вы можете взять один физический коммутатор и разделить его на несколько виртуальных коммутаторов, каждый со своими портами, своим broadcast-доменом и своей логикой.


Аналогия: Одно большое здание (коммутатор) разделено на несколько изолированных комнат (VLAN). Жильцы разных комнат не видят и не слышат друг друга, даже если находятся в одном здании.


Зачем нужны VLAN (проблемы без VLAN)

Без VLAN вся сеть — один broadcast-домен:
· Все устройства видят весь broadcast-трафик (ARP, DHCP, и т.д.)
· При 100+ устройствах broadcast-шум становится проблемой
· Трафик между отделами не изолирован (бухгалтерия видит трафик IT)
· Изменение топологии требует переподключения кабелей


С VLAN:
· Broadcast-домены разделены → меньше шума
· Безопасность — трафик между VLAN не ходит без маршрутизатора
· Гибкость — устройство можно перенести в другую VLAN без переподключения кабеля
· Экономия — один коммутатор = несколько логических сегментов


Как идентифицируется VLAN

| Идентификатор | Диапазон | Назначение                                                                                                                 |
| ------------- | -------- | -------------------------------------------------------------------------------------------------------------------------- |
| VLAN ID       | 1–4094   | Номер VLAN (включая 1–1005 для обычных, 1006–4094 для расширенных)                                                         |
| VLAN 1        | —        | По умолчанию, все порты в VLAN 1. Не рекомендуется использовать для пользовательского трафика по соображениям безопасности |
| Native VLAN   | —        | VLAN, которая не тегируется в trunk-канале (обычно VLAN 1, рекомендуется менять)                                           |


>[!important] VLAN 1 существует по умолчанию. Её нельзя удалить. Все порты по умолчанию находятся в VLAN 1. Используйте её только для управления, не для пользователей.

Типы портов (Access vs Trunk)

| Тип порта | Назначение                                                 | Как работает                                                                          |
| --------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Access    | Подключение конечных устройств (ПК, принтеры, телефоны)    | Порт принадлежит одной VLAN. Устройство не знает о VLAN — кадры отправляются без тега |
| Trunk     | Подключение коммутаторов друг к другу или к маршрутизатору | Порт принадлежит многим VLAN. Кадры тегируются меткой VLAN (IEEE 802.1Q)              |

Тегирование VLAN (IEEE 802.1Q)

Когда кадр проходит через trunk, к нему добавляется тег VLAN:


| Поле Ethernet-кадра | До тегирования | После тегирования                        |
| ------------------- | -------------- | ---------------------------------------- |
| Destination MAC     | 6 байт         | 6 байт                                   |
| Source MAC          | 6 байт         | 6 байт                                   |
| Type / Length       | 2 байта        | байта (0x8100 — указатель, что это VLAN) |
| VLAN Tag (802.1Q)   | —              | 4 байта (12 бит — VLAN ID)               |
| Data                | 46–1500 байт   | 46–1500 байт                             |
| FCS                 | 4 байта        | 4 байта                                  |

Итого: Кадр с тегом становится на 4 байта длиннее. В современных сетях это поддерживается автоматически.

Команды Cisco для VLAN

Создание VLAN:
```cisco
Switch(config)# vlan 10
Switch(config-vlan)# name Sales
Switch(config-vlan)# exit
```


Настройка Access-порта:
```cisco
Switch(config)# interface fastEthernet 0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
```


Настройка Trunk-порта:
```cisco
Switch(config)# interface gigabitEthernet 0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk allowed vlan 10,20,30
```


Просмотр VLAN:
```cisco
Switch# show vlan brief
```


>[!note] Эти команды показываются для понимания, а не для заучивания. Настройка будет разбираться в практических лабах.


МежVLAN-маршрутизация (как общаются разные VLAN)

Проблема: Устройства в разных VLAN не видят друг друга (это их главное преимущество). Но иногда им нужно общаться — например, пользователи VLAN 10 (Sales) должны иметь доступ к серверу в VLAN 20 (Servers).


Решение: Маршрутизатор или L3-коммутатор между VLAN.


Три варианта реализации:


| Способ                         | Как работает                                                                                                             | Где используется                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------- |
| Router-on-a-stick              | Один физический интерфейс роутера → Trunk → Коммутатор. На роутере — субинтерфейсы для каждой VLAN                       | Малые сети, один роутер                   |
| L3-коммутатор (SVI)            | На коммутаторе создаются виртуальные интерфейсы (SVI) для каждой VLAN. Коммутатор сам выполняет маршрутизацию между VLAN | Крупные сети, дата-центры                 |
| Отдельный физический интерфейс | На роутере — отдельный порт для каждой VLAN. Неэффективно, но просто                                                     | Очень маленькие сети, лабораторные стенды |


Важно: Для общения VLAN нужен L3-устройство (роутер или L3-коммутатор). Обычный L2-коммутатор не может маршрутизировать между VLAN.
