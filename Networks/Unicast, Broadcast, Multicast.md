**Unicast, Broadcast, Multicast**

Зачем нужны эти типы
В сети нужно отправлять данные трёмя разными способами:
- **Одному** конкретному устройству
- **Всем** устройствам в сети
- **Группе** устройств

Каждый тип используется в разных ситуациях.

**Unicast (Один — одному)**

**Суть:** Сообщение отправляется **одному конкретному получателю**.

**Аналогия:** Письмо с точным адресом (город, улица, дом, квартира).

**Как работает:**
- Source IP / Source MAC — отправитель
- Destination IP / Destination MAC — получатель
- Получатель **один**

**Где используется:**
- Веб-сёрфинг (вы открываете сайт — ответ идёт только вам)
- Загрузка файла с сервера
- `ping` до конкретного IP
- Email

**Пример:** Вы смотрите YouTube — данные идут с сервера Google **только к вашему компьютеру**.

**Сколько трафика:** >90% всего сетевого трафика — это Unicast.

**Broadcast (Один — всем)**

**Суть:** Сообщение отправляется **всем устройствам в локальной сети (broadcast domain)**.

**Аналогия:** Объявление по громкоговорителю в здании — все слышат, кто заинтересован — реагирует.

**Как работает:**
- Destination IP: `255.255.255.255` (ограниченный broadcast) или последний адрес в сети (например, `192.168.1.255`)
- Destination MAC: `FF:FF:FF:FF:FF:FF`
- Все устройства в сети получают кадр, но не все его обрабатывают

> [!note] Маршрутизатор **не пропускает** broadcast-трафик из одной сети в другую. Broadcast остаётся внутри своей VLAN/L2-сети.

**Где используется:**
- **ARP-запрос:** «Кто имеет IP 192.168.1.1? Сообщи свой MAC»
- **DHCP-запрос:** клиент ищет DHCP-сервер
- Проверка связи со всеми устройствами в сегменте

**Пример:** Вы подключились к сети. Ваш компьютер ещё не имеет IP и отправляет DHCP Discover на `255.255.255.255` — все слышат, но только DHCP-сервер отвечает.

**Проблема broadcast:** Чем больше устройств в сети, тем больше broadcast-трафика. Это создаёт нагрузку на все устройства. Решение — VLAN'ы (делят broadcast domain).

**Multicast (Один — группе)**

**Суть:** Сообщение отправляется **группе устройств**, которые «подписались» на этот трафик.

**Аналогия:** Подписка на рассылку. Получают только те, кто подписался.

**Как работает:**
- Есть группа — специальный Multicast-IP (от `224.0.0.0` до `239.255.255.255`)
- Устройства «подписываются» на группу через **IGMP (Internet Group Management Protocol)**
- Отправитель шлёт один поток данных, а маршрутизаторы копируют его только тем, кто подписан

> [!tip] Multicast работает и на L2 (MAC-адреса для multicast начинаются с `01:00:5E`), и на L3 (специальные IP-адреса групп).

**Где используется:**
- IP-телевидение (IPTV) — один канал, много зрителей
- Видеоконференции (один спикер, много участников)
- Протоколы маршрутизации (OSPF, EIGRP используют multicast для обмена маршрутами)
- Cisco Discovery Protocol (CDP)

**Пример:** Трансляция футбольного матча через IPTV. Сервер отправляет поток один раз, а маршрутизаторы дублируют его только тем абонентам, которые смотрят этот канал. Это экономит пропускную способность по сравнению с Unicast (не нужно слать каждому копию).

### 📊 Сравнительная таблица

| Характеристика | Unicast | Broadcast | Multicast |
|----------------|---------|-----------|-----------|
| **Получатель** | Один | Все в сети | Группа (подписчики) |
| **IP-адрес назначения** | Конкретный IP | `255.255.255.255` или последний в сети | `224.0.0.0` — `239.255.255.255` |
| **MAC-адрес назначения** | MAC получателя | `FF:FF:FF:FF:FF:FF` | Начинается с `01:00:5E` |
| **Проходит через роутер** | Да (маршрутизируется) | Нет (остаётся в сегменте) | Да (но только подписчикам) |
| **Пример** | HTTP, SSH, ping | ARP, DHCP Discover | IPTV, OSPF, EIGRP |
| **Нагрузка на сеть** | Минимальная (только адресату) | Высокая (все получают) | Средняя (только подписчики) |

---

### 🔑 Ключевые выводы

| Тип | Когда использовать |
|-----|-------------------|
| **Unicast** | Повседневная работа — веб, почта, загрузка файлов |
| **Broadcast** | Служебные запросы (ARP, DHCP). Нужно минимизировать через VLAN'ы |
| **Multicast** | Потоковые данные на много устройств (видео, аудио, маршрутизация) |

---

### 🎯 Итог одной фразой

> **Unicast** — это письмо одному человеку.  
> **Broadcast** — это объявление по громкоговорителю всем.  
> **Multicast** — это подписка на рассылку только для заинтересованных.
