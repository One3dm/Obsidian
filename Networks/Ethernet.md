Ethernet

**Ethernet** — это основной протокол канального уровня (L2), используемый в локальных сетях (LAN). Определён стандартом **IEEE 802.3**.

**Где используется:** Дома, в офисе, в дата-центрах — везде, где есть проводная локальная сеть.

 Скорости Ethernet (эволюция)

| Стандарт | Скорость | Появился | Где используется сейчас |
|----------|----------|----------|--------------------------|
| **Ethernet** | 10 Мбит/с | 1980-е | Устарел, почти не встречается |
| **Fast Ethernet** | 100 Мбит/с | 1995 | Всё ещё есть в старых сетях |
| **Gigabit Ethernet** | 1000 Мбит/с (1 Гбит/с) | 1999 | **Стандарт** для ПК, свитчей, серверов |
| **10 Gigabit Ethernet** | 10 Гбит/с | 2002 | Дата-центры, магистрали |
| **40/100 Gigabit Ethernet** | 40–100 Гбит/с | 2010 | Крупные дата-центры, провайдеры |

**Важно:** Скорость измеряется в **битах в секунду (bps)**.  
1 Мбит/с = 1 000 000 бит/с.  
Не путать с **мегабайтами** (1 байт = 8 бит). Файлы измеряются в байтах, скорость — в битах.

> [!example] Если у вас тариф 100 Мбит/с, то максимальная скорость загрузки файлов ≈ 12.5 Мбайт/с (100 / 8 = 12.5).

### 🧩 Структура Ethernet-кадра

**Ethernet II** — самый распространённый формат кадра в современных сетях.

| Поле | Размер (байт) | Что значит |
|------|---------------|------------|
| **Preamble** | 7 | Синхронизация (не виден на уровне пакетов) |
| **SFD** | 1 | Начало кадра (Start Frame Delimiter) |
| **Destination MAC** | 6 | MAC-адрес получателя |
| **Source MAC** | 6 | MAC-адрес отправителя |
| **Type / Length** | 2 | Тип протокола внутри (например, 0x0800 = IPv4) |
| **Data (Payload)** | 46–1500 | Данные (IP-пакет, ARP-пакет и т.д.) |
| **FCS (Frame Check Sequence)** | 4 | Контрольная сумма для проверки ошибок |

![[Ethernet_frame.png]]

> [!note] Минимальный размер кадра — 64 байта (без преамбулы). Если данных меньше 46 байт, добавляется padding.

### 🔍 Type vs Length (важно!)

В Ethernet II поле **Type** указывает, какой протокол находится внутри кадра:

| Значение (hex) | Протокол |
|----------------|----------|
| `0x0800` | IPv4 |
| `0x0806` | ARP |
| `0x86DD` | IPv6 |
| `0x8100` | VLAN (802.1Q) |

> [!tip] Это позволяет принимающему устройству понять, какому протоколу передать данные (например, IP-стеки или ARP).

### 🔁 Как работает Ethernet в сети

**На коммутаторе (L2):**
1. Получает кадр.
2. Смотрит на **Destination MAC**.
3. Ищет этот MAC в своей **MAC-таблице (CAM-таблица)**.
   - Если знает порт → отправляет только на этот порт (Unicast).
   - Если не знает → **Flooding** (отправляет на все порты, кроме входящего).
   - Если MAC = `FF:FF:FF:FF:FF:FF` → **Broadcast** (всем).

**MAC-таблица коммутатора:**

| MAC-адрес | Порт |
|-----------|------|
| `AA:BB:CC:DD:EE:01` | Gi0/1 |
| `AA:BB:CC:DD:EE:02` | Gi0/2 |

### ⚠️ CSMA/CD (исторически)

**CSMA/CD (Carrier Sense Multiple Access with Collision Detection)** — механизм, который использовался в старых Ethernet-сетях на **хабах** (полудуплекс).

**Как работал:**
1. Устройство слушает канал.
2. Если свободен — передаёт.
3. Если два устройства передают одновременно → **коллизия**.
4. Оба останавливаются, ждут случайное время и повторяют попытку.

> [!important] В современных сетях на **коммутаторах** и **полном дуплексе** CSMA/CD **не используется**. Коллизий нет, потому что для приёма и передачи используются отдельные пары в кабеле.

### 📊 Сравнение: Hub vs Switch (связь с дуплексом)

| Характеристика | Hub (Концентратор) | Switch (Коммутатор) |
|----------------|-------------------|---------------------|
| **Режим передачи** | Полудуплекс | Полный дуплекс |
| **Коллизии** | Есть (CSMA/CD) | Нет |
| **Домен коллизий** | Один на всех | На каждый порт |
| **Скорость** | Общая полоса на всех | Полная полоса на каждый порт |
| **Где используется** | Устарел | Везде |

### 🎯 Итог

| Вопрос | Ответ |
|--------|-------|
| **Что такое Ethernet?** | Протокол канального уровня для локальных сетей (IEEE 802.3) |
| **Какие скорости бывают?** | 10 Мбит/с → 100 Мбит/с → 1 Гбит/с → 10 Гбит/с → 100 Гбит/с |
| **Из чего состоит кадр?** | Destination MAC, Source MAC, Type, Data, FCS |
| **Как коммутатор работает?** | По MAC-таблице: unicast, flooding, broadcast |
| **Что такое CSMA/CD?** | Механизм для полудуплексных сетей (устарел) |
| **Чем свитч лучше хаба?** | Полный дуплекс, нет коллизий, полная скорость на порт |
