**re.escape**

Проблема: спецсимволы в строке поиска

Строка может содержать символы, которые в регулярных выражениях имеют особое значение (например, `[`, `]`, `$`, `*`, `+`, `?`, `.`, `(`, `)`, `^`, `{`, `}`, `|`, `\`).

```python
prompt = "[lp] One@3dm $"
```

Квадратные скобки `[ ]` и символ `$` — это спецсимволы regex. Если передать их напрямую в `re.search()`, они будут интерпретироваться не как буквальные символы.


## Решение: `re.escape()`

Функция `re.escape()` автоматически экранирует все спецсимволы, превращая строку в **буквальный** шаблон.

```python
prompt_literal = re.escape(prompt)
print(prompt_literal)
# \[lp\] ktbyers@pydev2\ \$
```

Теперь `[` стал `\[`, `]` стал `\]`, а `$` стал `\$` — каждый символ ищется буквально.

---

## 📌 Итог

| Без `re.escape()` | С `re.escape()` |
|------------------|-----------------|
| Спецсимволы имеют особое значение | Все символы ищутся буквально |
| Может дать неожиданные результаты | Безопасный поиск точной строки |

```python
import re

prompt = "[lp] ktbyers@pydev2 $"
literal_pattern = re.escape(prompt)

match = re.search(literal_pattern, output)
```
