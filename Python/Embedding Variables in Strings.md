**Вставка переменных в строки**

В Python есть **три способа** вставить переменные в строку.

Оператор `%` (старый стиль, как в C)

```python
# Одна переменная
"Это строка: %s" % "привет"
# 'Это строка: привет'

my_var = "Hello"
"Это строка: %s" % my_var
# 'Это строка: Hello'

# Несколько переменных — нужен кортеж
"Это строка: %s %s" % (my_var, "hello")
# 'Это строка: Hello hello'
```

Метод `.format()` (появился в Python 3)

```python
"Это строка: {} {}".format(my_var, "hello")
# 'Это строка: Hello hello'
```

f-строки (Python 3.6+, **рекомендуемый способ**)

```python
my_var = "Hello"
my_var2 = "hello"

f"Это строка: {my_var} {my_var2}"
# 'Это строка: Hello hello'
```

Внутри `{}` можно писать любые выражения:
```python
f"Сумма: {5 + 3}"        # 'Сумма: 8'
f"IP: {ip.upper()}"      # можно вызывать методы
```

Сравнение способов

| Способ | Пример | Когда использовать |
|--------|--------|-------------------|
| `%` | `"%s %s" % (a, b)` | Почти не используется |
| `.format()` | `"{} {}".format(a, b)` | Редко, если нужна совместимость с Python 3.5- |
| **f-строки** | `f"{a} {b}"` | **Всегда в современном коде** |

> [!TIP]
> Существует 3 три способа, но **рекомендуется использовать f-строки** — они самые читаемые и быстрые.

📌 Итог

```python
# ✅ Лучший способ (f-строки)
name = "мир"
print(f"Привет, {name}!")

# ⚠️ Устаревшие способы (знать, но не использовать)
print("Привет, %s!" % name)
print("Привет, {}!".format(name))
```
