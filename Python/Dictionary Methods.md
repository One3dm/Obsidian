***Методы словарей**

Удаление элементов

`.pop()` — удалить и вернуть значение

Метод `.pop()` удаляет ключ из словаря и **возвращает** соответствующее значение.
```python
my_dict = {
    "rtr1": "10.100.1.1",
    "rtr2": "10.100.2.1",
    "rtr3": "10.100.100.1",
    "rtr4": "10.99.1.1"
}

ret_val = my_dict.pop("rtr4")
print(ret_val)        # 10.99.1.1
print(my_dict)        # {'rtr1': '10.100.1.1', 'rtr2': '10.100.2.1', 'rtr3': '10.100.100.1'}
```

> [!NOTE]
> Если ключ не найден, `.pop()` выбрасывает `KeyError`. Можно передать значение по умолчанию: `my_dict.pop("rtr5", None)`.


`del` — удалить ключ

Оператор `del` удаляет ключ, но **не возвращает** значение.
```python
del my_dict["rtr4"]
```


Объединение словарей — `.update()`

Метод `.update()` добавляет все пары «ключ-значение» из другого словаря. Если ключ существует — значение **заменяется**.
```python
ca_routers = {
    "rtr1": "10.100.1.1",
    "rtr2": "10.100.2.1",
    "rtr3": "10.100.100.1"
}

la_routers = {
    "la-rtr1": "10.101.254.1",
    "la-rtr2": "10.101.254.2",
    "rtr3": "192.168.200.1"      # ключ rtr3 уже есть в ca_routers
}

ca_routers.update(la_routers)
```

**Результат:**

```python
{
    "rtr1": "10.100.1.1",
    "rtr2": "10.100.2.1",
    "rtr3": "192.168.200.1",      # значение обновлено
    "la-rtr1": "10.101.254.1",    # новый ключ
    "la-rtr2": "10.101.254.2"     # новый ключ
}
```

> [!TIP]
> `.update()` изменяет исходный словарь. Чтобы создать новый, используйте `new_dict = {**dict1, **dict2}` (Python 3.5+) или `new_dict = dict1 \| dict2` (Python 3.9+).


Сводная таблица методов

| Метод/Оператор | Назначение | Возвращает |
|----------------|------------|------------|
| `.pop(key)` | Удаляет ключ и возвращает значение | Значение |
| `del dict[key]` | Удаляет ключ | Ничего (None) |
| `.update(other)` | Добавляет пары из другого словаря | `None` |

📌 Итог

```python
# Удаление с получением значения
value = my_dict.pop("key")

# Удаление без получения значения
del my_dict["key"]

# Объединение (изменяет исходный словарь)
dict1.update(dict2)
```
