**Дополнительные примеры: извлечение версии**

Исходные данные (строка из `show version`)
```python
line = "Cisco IOS Software [Fuji], ISR Software (ARMv8EB_LINUX_IOSD-UNIVERSALK9_IAS-M), Version 16.8.1, RELEASE SOFTWARE (fc3)"
```

Пошаговое построение шаблона

1. Якорь начала `^` и жадный `.*`
```python
m = re.search(r"^Cisco.*\d+", line)
print(m.group(0))   # вся строка
```

`\d+` требует **хотя бы одну цифру** в конце. Жадный `.*` съедает почти всё, оставляя последние цифры.


2. Уточняем: две цифры подряд `\d\d`
```python
m = re.search(r"^Cisco.*\d\d", line)
print(m.group(0))   # 'Cisco IOS ... Version 16'
```

Остановился на двух цифрах (`16`).

3. Добавляем формат версии (`\d\d\.\d\d\.\d`)

```python
m = re.search(r"^Cisco.*\d\d\.\d\d\.\d", line)
print(m.group(0))   # 'Cisco IOS ... Version 16.8.1'
```

Точки экранированы (`\.`), чтобы искать **буквальную точку**.

4. Добавляем группу `(\d\d\.\d\d\.\d)`

Скобки `()` запоминают часть строки.

```python
m = re.search(r"^Cisco.*(\d\d\.\d\d\.\d)", line)
print(m.group(0))   # вся найденная строка (как в шаге 3)
print(m.group(1))   # '16.8.1'  — только версия
```

5. Свой класс символов `[\d\.]`

```python
m = re.search(r"^Cisco.*[\d\.]+", line)
print(m.group(0))   # вся строка
```

`[\d\.]+` — один или более символов, каждый из которых **цифра** или **точка**.


6. Уточняем: `[\d\.]+` до `, REL`
```python
m = re.search(r"^Cisco.*[\d\.]+, REL", line)
print(m.group(0))   # 'Cisco ... Version 16.8.1, REL'
# Группы нет — скобок нет, поэтому m.group(1) ошибка
```


7. Добавляем группу вокруг `([\d\.]+)`
```python
m = re.search(r"^Cisco.*([\d\.]+), REL", line)
print(m.group(1))   # '1' (только последняя цифра, а не вся версия!)
```

Почему? Жадный `.*` захватил максимум, оставив только `1` в группе.


8. Исправляем: сужаем левую часть до `"ion "`
```python
m = re.search(r"^Cisco.*ion ([\d\.]+), REL", line)
print(m.group(1))   # '16.8.1'
```

Теперь левая часть `.*` останавливается перед `"ion "`, и группа забирает **всю версию** до `, REL`.


Сравнение шаблонов

| Шаг | Шаблон | Результат группы |
|-----|--------|------------------|
| 4 | `^Cisco.*(\d\d\.\d\d\.\d)` | `'16.8.1'` |
| 7 | `^Cisco.*([\d\.]+), REL` | `'1'` (неправильно) |
| 8 | `^Cisco.*ion ([\d\.]+), REL` | `'16.8.1'` (правильно) |


Ключевые выводы
1. **Группы `()`** запоминают часть найденного.
2. **Жадность** `.*` может «забирать» лишнее — сужайте левую часть, используя конкретные слова (`"ion "`).
3. **Собственные классы** `[\d\.]` удобны для версий и IP-адресов (цифры и точки).
4. **Экранирование точки** `\.` обязательно для поиска буквальной точки.
