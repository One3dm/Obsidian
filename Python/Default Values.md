**Значения по умолчанию (Default Values)**

Синтаксис

Параметру можно задать **значение по умолчанию**:
```python
def display_output(msg1, msg2, msg3="Hello World"):
    print(f"msg1: {msg1}")
    print(f"msg2: {msg2}")
    print(f"msg3: {msg3}")
```

- `msg3` имеет значение по умолчанию `"Hello World"`
- Если при вызове не передать `msg3` — будет использовано значение по умолчанию


Пример вызова
```python
display_output(msg2="foo", msg1="Something")
```

Вывод:
```
msg1: Something
msg2: foo
msg3: Hello World
```

Аргумент для `msg3` не передан — используется `"Hello World"`.


Переопределение значения по умолчанию

Если передать аргумент, он **переопределит** значение по умолчанию:

```python
display_output("One", "Two", "Custom value")
# msg3: Custom value
```


Зачем это нужно

- **Удобство** — не нужно передавать одни и те же значения каждый раз
- **Расширяемость** — можно добавить новый параметр со значением по умолчанию, не ломая существующий код


📌 Итог

| Правило | Пример |
|---------|--------|
| Параметр со значением по умолчанию можно не указывать при вызове | `func(a=1, b=2)` |
| Если указать — переопределяет значение по умолчанию | `func(a=1, b=2, c=3)` |
| Параметры со значениями по умолчанию обычно идут **после** обязательных | `def func(a, b, c=10):` |
