**Передача аргументов с помощью `*args`**

Проблема

Что если у нас есть список значений, и мы хотим передать **каждый элемент списка** как отдельный аргумент в функцию?

```python
def print_ips(ip_addr1, ip_addr2):
    print(f"{ip_addr1=}")
    print(f"{ip_addr2=}")

sf_addresses = ["10.1.1.1", "10.1.1.2"]
```


❌ Неправильно: передача списка целиком

```python
print_ips(sf_addresses)
# TypeError: print_ips() missing 1 required positional argument: 'ip_addr2'
```

Весь список `sf_addresses` передаётся как **один аргумент** (в `ip_addr1`), а `ip_addr2` остаётся без значения.


✅ Правильно: распаковка списка с помощью `*`

Звёздочка `*` перед списком (или кортежем) в **вызове функции** означает: "передай элементы этого списка как отдельные аргументы **по порядку**".

```python
print_ips(*sf_addresses)
```

- `"10.1.1.1"` → `ip_addr1`
- `"10.1.1.2"` → `ip_addr2`


Сравнение

| Код | Что передаётся |
|-----|----------------|
| `print_ips(sf_addresses)` | Один аргумент — список |
| `print_ips(*sf_addresses)` | Два аргумента — элементы списка |


Когда это полезно

- Когда у вас уже есть данные в виде списка/кортежа
- Когда функция требует несколько аргументов, а количество элементов заранее неизвестно
- Для передачи в функции, которые принимают переменное количество аргументов (например, `max()`, `min()`)

```python
numbers = [1, 5, 2, 8, 3]
print(max(*numbers))   # 8
```


📌 Итог

```python
# * в вызове функции — распаковка итерируемого объекта в отдельные аргументы
def my_func(a, b, c):
    pass

my_list = [1, 2, 3]
my_func(*my_list)   # a=1, b=2, c=3
```
