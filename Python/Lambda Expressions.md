Lambda-выражения

Lambda — это способ создать **однострочную анонимную функцию** (без имени) с ограниченными возможностями.

```python
lambda x: x**2
```


Синтаксис

```python
lambda аргументы: возвращаемое_выражение
```

- `lambda` — ключевое слово
- `аргументы` — переменные, которые передаются в функцию
- `:` — разделитель
- `возвращаемое_выражение` — то, что возвращается (всегда **одно выражение**, не может содержать полноценные операторы)

```python
lambda x, y: x ** y   # два аргумента
```

Присваивание переменной и вызов

```python
my_func = lambda x, y: x ** y

my_func(2, 3)        # 8 (позиционные аргументы)
my_func(x=2, y=4)    # 16 (именованные аргументы)
```

> [!NOTE]
> Lambda — это анонимная функция, но её можно присвоить переменной, чтобы вызывать по имени.


Практическое применение: сортировка

### Проблема: сортировка строк

```python
words = ['This', 'is', 'a', 'string', 'with', 'some', 'random', 'Words', 'Capitalized']

sorted(words)
# ['Capitalized', 'This', 'Words', 'a', 'is', 'random', 'some', 'string', 'with']
```

По умолчанию сортировка по ASCII-коду (заглавные буквы идут раньше строчных).

Решение: параметр `key`

```python
# Используя метод str.lower
sorted(words, key=str.lower)
# ['a', 'Capitalized', 'is', 'random', 'some', 'string', 'This', 'with', 'Words']

# Используя lambda
sorted(words, key=lambda word: word.lower())
# ['a', 'Capitalized', 'is', 'random', 'some', 'string', 'This', 'with', 'Words']
```

Lambda получает каждый элемент, возвращает значение для сравнения.


Сортировка списка кортежей

```python
persons = [('John', 22), ('Sally', 33), ('Anne', 87)]

# По умолчанию — по первому элементу кортежа
sorted(persons)
# [('Anne', 87), ('John', 22), ('Sally', 33)]

# Сортировка по возрасту (второй элемент)
sorted(persons, key=lambda person_tuple: person_tuple[1])
# [('John', 22), ('Sally', 33), ('Anne', 87)]
```

📌 Итог

| Характеристика | Lambda | Обычная функция |
|----------------|--------|-----------------|
| Имя | Анонимная (можно присвоить) | Есть имя |
| Строки | Одна строка | Любое количество |
| `return` | Неявный (выражение после `:`) | Явный `return` |
| Где полезна | Передача в `key`, `map`, `filter` | Сложная логика |

```python
# Типичное применение
sorted(data, key=lambda x: x[1])
```
