**Циклы `for`**

Синтаксис

```python
ip_list = [
    "10.88.17.1",
    "10.88.17.2",
    "10.88.17.20",
    "10.88.17.21"
]

for ip in ip_list:
    print(ip)
```

```
10.88.17.1
10.88.17.2
10.88.17.20
10.88.17.21
```

**Как работает:**
- `for` — ключевое слово
- `ip` — переменная цикла (на каждой итерации получает следующий элемент)
- `in` — разделитель
- `ip_list` — итерируемый объект (список, строка, кортеж, множество, словарь и т.д.)

 
Что можно перебирать

| Тип | Пример | Результат |
|-----|--------|-----------|
| `list` | `[1, 2, 3]` | `1`, `2`, `3` |
| `str` | `"hello"` | `'h'`, `'e'`, `'l'`, `l'`, `'o'` |
| `tuple` | `(1, 2, 3)` | `1`, `2`, `3` |
| `range()` | `range(3)` | `0`, `1`, `2` |

```python
for letter in "some string":
    print(letter)
```


`break` — немедленный выход из цикла

```python
for i in range(10):
    print(i)
    if i == 5:
        break
    print(f"Outside loop --> {i}")
```

```
0
Outside loop --> 0
1
Outside loop --> 1
2
Outside loop --> 2
3
Outside loop --> 3
4
Outside loop --> 4
5
```

> [!NOTE]
> `break` прерывает цикл полностью. Код после `break` внутри цикла не выполняется.


`continue` — переход к следующей итерации
```python
for i in range(10):
    if i == 5:
        continue
    print(i)
```

Пропускает `i == 5`, остальные числа печатаются.

> [!NOTE]
> `continue` перепрыгивает сразу на следующую итерацию, не выполняя оставшийся код в блоке.


Вложенные циклы

```python
data_centers = [
    ("sf1", "10.1.1."),
    ("sf2", "10.1.2.")
]

for dc, base_addr in data_centers:
    for net_addr in range(1, 5):
        print(f"{dc} --> {base_addr}{net_addr}")
```

```
sf1 --> 10.1.1.1
sf1 --> 10.1.1.2
sf1 --> 10.1.1.3
sf1 --> 10.1.1.4
sf2 --> 10.1.2.1
sf2 --> 10.1.2.2
sf2 --> 10.1.2.3
sf2 --> 10.1.2.4
```

Внутренний цикл полностью отрабатывает для каждой итерации внешнего.


`enumerate()` — индекс и значение
```python
data_centers = ["sf1", "sf2", "la1", "la2", "dallas"]

for i, dc in enumerate(data_centers):
    print(f"{i} --> {dc}")
```

```
0 --> sf1
1 --> sf2
2 --> la1
3 --> la2
4 --> dallas
```


Пустой список

Если итерируемый объект пуст, цикл просто **не выполняется**:

```python
for element in []:
    print("Это не напечатается")
```


`pass` — ничего не делать

Используется как заглушка там, где синтаксис требует блок кода, а делать пока ничего не нужно:

```python
for dc in data_centers:
    pass   # TODO: добавить логику позже
```

`else` в цикле `for`

Блок `else` выполняется, если цикл **не был прерван** `break`:

```python
for i in range(10):
    print(i)
    if i == 5:
        break
else:
    print("No 'break' happened")   # не выполнится, был break

for i in range(10):
    print(i)
    if i == 12:    # условие никогда не сработает
        break
else:
    print("No 'break' happened")   # выполнится
```

> [!TIP]
> `for-else` встречается редко, но иногда полезно для поиска элементов.


📌 Итог

| Ключевое слово | Что делает |
|----------------|------------|
| `for var in iterable:` | Перебирает элементы |
| `break` | Немедленный выход из цикла |
| `continue` | Переход к следующей итерации |
| `pass` | Ничего не делать (заглушка) |
| `else` | Выполняется, если не было `break` |
| `enumerate()` | Даёт индекс и значение |
