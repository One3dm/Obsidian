Множества (Sets)

Что такое множество

**Множество (set)** — неупорядоченная коллекция **уникальных** элементов.

```python
addresses = {"192.168.100.1", "192.168.100.2", "192.168.100.3"}
type(addresses)   # set
```

> [!NOTE]
> В других языках множества часто называют **хэш-таблицами** или просто **сетами**.


Характеристики множеств

| Свойство | Описание |
|----------|----------|
| **Неупорядоченность** | Элементы не имеют индекса |
| **Уникальность** | Дубликаты автоматически удаляются |
| **Изменяемость** | Можно добавлять и удалять элементы |
| **Быстрый поиск** | O(1) для проверки вхождения |



Создание и основные операции

Дубликаты удаляются автоматически
```python
addresses = {"192.168.100.1", "192.168.100.2", "192.168.100.1"}
# {'192.168.100.1', '192.168.100.2'}
```

Доступ по индексу — невозможен
```python
addresses[0]   # ❌ TypeError: 'set' object is not subscriptable
```


Добавление элементов

`.add()` — добавить один элемент
```python
addresses.add("10.1.1.1")
```

`.update()` — добавить несколько элементов (из другого множества или коллекции)
```python
addresses.update({"10.1.1.1", "10.1.1.2"})
```


Удаление элементов

| Метод | Поведение при отсутствии элемента |
|-------|----------------------------------|
| `.remove(x)` | ❌ вызывает `KeyError` |
| `.discard(x)` | ✅ не вызывает ошибку |

```python
addresses.remove("10.1.1.1")    # KeyError, если элемента нет
addresses.discard("10.1.1.1")   # ничего не произойдёт, если элемента нет
```



Операции над множествами

Рассмотрим на примере:

```python
sf_addresses = {
    "192.168.100.1",
    "192.168.100.2",
    "10.1.1.1",
    "10.1.1.2"
}

la_addresses = {
    "10.1.1.1",
    "10.220.33.1",
    "10.220.33.2"
}
```

1. Объединение (`|` или `.union()`)

Все элементы из обоих множеств (без дубликатов).

```python
sf_addresses | la_addresses
# {'10.1.1.1', '10.1.1.2', '10.220.33.1', '10.220.33.2', '192.168.100.1', '192.168.100.2'}
```

2. Пересечение (`&` или `.intersection()`)

Элементы, которые есть в обоих множествах.

```python
sf_addresses & la_addresses
# {'10.1.1.1'}
```

3. Разность (`-` или `.difference()`)

Элементы из первого множества, которых нет во втором.

```python
sf_addresses - la_addresses
# {'10.1.1.2', '192.168.100.1', '192.168.100.2'}

la_addresses - sf_addresses
# {'10.220.33.1', '10.220.33.2'}   # направление важно!
```

4. Симметрическая разность (`^` или `.symmetric_difference()`)

Элементы, которые есть только в одном из множеств (исключая пересечение).

```python
sf_addresses ^ la_addresses
# {'10.1.1.2', '10.220.33.1', '10.220.33.2', '192.168.100.1', '192.168.100.2'}
```


Сводная таблица операций

| Операция | Символ | Метод | Результат |
|----------|--------|-------|-----------|
| Объединение | `\|` | `.union()` | Все элементы из обоих |
| Пересечение | `&` | `.intersection()` | Общие элементы |
| Разность | `-` | `.difference()` | Из первого, исключая второе |
| Симметрическая разность | `^` | `.symmetric_difference()` | Из обоих, исключая общие |


📌 Итог

```python
# Создание
my_set = {1, 2, 3}

# Добавление
my_set.add(4)
my_set.update([5, 6])

# Удаление
my_set.remove(4)    # KeyError, если нет
my_set.discard(7)   # безопасно

# Операции
union = sf \| la
intersection = sf & la
diff = sf - la
sym_diff = sf ^ la
```

> [!TIP]
> Множества отлично подходят для:
> - Хранения уникальных значений (например, уникальные IP-адреса)
> - Быстрой проверки вхождения (`if ip in allowed_ips:`)
> - Удаления дубликатов из списка: `list(set(my_list))`
