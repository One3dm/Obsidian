**Чтение из файла**

## Открытие файла

```python
f = open("show_version.txt")
```

По умолчанию `open()` открывает файл в **текстовом режиме** (`'r'` — read).

```python
f
# <_io.TextIOWrapper name='show_version.txt' mode='r' encoding='UTF-8'>
```

---

## Основные методы чтения

| Метод | Что делает | Результат |
|-------|-----------|-----------|
| `.read()` | Читает весь файл целиком | Одна строка (str) |
| `.readline()` | Читает одну строку | Строка (str) |
| `.readlines()` | Читает все строки в список | Список строк (list) |
| Цикл `for line in f` | Итерация по строкам | По одной строке за раз |

---

### Примеры

#### `.read()` — весь файл как одна строка

```python
f = open("show_version.txt")
data = f.read()
f.close()
```

#### `.readline()` — построчно

```python
f = open("show_version.txt")
first_line = f.readline()   # первая строка
second_line = f.readline()  # вторая строка
f.close()
```

#### `.readlines()` — в список

```python
f = open("show_version.txt")
data = f.readlines()         # список строк
len(data)                    # количество строк в файле
f.close()
```

#### Цикл по файлу (самый эффективный)

```python
f = open("show_version.txt")
for line in f:
    print(line)              # обрабатываем строку
f.close()
```

---

## Важно: закрывать файл

После работы с файлом его нужно **закрыть**:

```python
f.close()
```

Если не закрыть:
- Могут потеряться данные (при записи)
- Системные ресурсы не освободятся
- При большом количестве файлов могут быть проблемы

> [!TIP]
> В следующем видео Kirk покажет **контекстные менеджеры** (`with`), которые закрывают файлы автоматически.

---

## Метод `.seek(0)`

Возвращает "курсор" в начало файла, чтобы читать заново:

```python
f.seek(0)   # перейти в начало
```

---

## 📌 Итог

| Метод | Возвращает | Когда использовать |
|-------|-----------|-------------------|
| `.read()` | `str` | Маленькие файлы |
| `.readline()` | `str` | Построчная обработка |
| `.readlines()` | `list` | Нужны все строки как список |
| `for line in f` | `str` | **Самый эффективный** для больших файлов |
