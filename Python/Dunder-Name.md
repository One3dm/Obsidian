 `if __name__ == "__main__"` — разделение кода


Конструкция `if __name__ == "__main__"` позволяет разделить код на две части:

1. **Импортируемые вещи** — функции, классы, константы (можно использовать в других программах)
2. **Исполняемый код** — код, который запускается только при прямом выполнении файла

Зачем это нужно

```python
def func1():
    print("Hello world!")

def func2():
    print("Something else")

if __name__ == "__main__":
    print("Starting my main program")
    func1()
    func2()
    print("All done")
```

- **При импорте**: файл загружается, но `func1()` и `func2()` **не выполняются**
- **При прямом запуске**: выполняется весь код, включая `func1()` и `func2()`


Как это работает

`__name__` — это специальная переменная, которую Python устанавливает автоматически:

| Ситуация | Значение `__name__` |
|----------|---------------------|
| Прямой запуск файла | `"__main__"` |
| Импорт файла | имя файла (без `.py`) |

```python
# main_ex4.py
print(__name__)
```

```bash
$ python main_ex4.py
__main__
```

```python
>>> import main_ex4
main_ex4
```


Структура кода

```python
# === ИМПОРТИРУЕМАЯ ЧАСТЬ ===

# Константы
PI = 3.14

# Функции
def func1():
    print("Hello world")

# Классы
class SomeClass:
    pass

# === ГРАНИЦА ===

if __name__ == "__main__":
    # === ИСПОЛНЯЕМАЯ ЧАСТЬ ===
    print("Main program")
    func1()
```


📌 Итог

```python
# Шаблон, который используется в каждом Python-файле
def main():
    # основной код программы
    pass

if __name__ == "__main__":
    main()
```

| Конструкция | Назначение |
|-------------|------------|
| `if __name__ == "__main__":` | Код выполняется только при прямом запуске |
| `main()` | Функция с основной логикой программы |
| Функции выше | Могут быть импортированы и переиспользованы |
