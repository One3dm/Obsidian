Многомерные списки

Что это такое
Список может содержать другие списки в качестве элементов:
```python
my_list = [[22, 18, 72], ["hello", "world"]]
# [[22, 18, 72], ['hello', 'world']]
```

Доступ к элементам

Первый уровень
```python
my_list[0]    # [22, 18, 72]
my_list[1]    # ['hello', 'world']
```

Второй уровень
```python
my_list[0][0]    # 22
my_list[0][1]    # 18
my_list[1][0]    # 'hello'
my_list[1][1]    # 'world'
```

Практические примеры

Таблица маршрутизации
```python
routing_table = [
    ["10.0.0.0/8", "192.168.1.1", "GigabitEthernet0/1"],
    ["172.16.0.0/12", "192.168.1.2", "GigabitEthernet0/2"],
    ["192.168.0.0/16", "192.168.1.3", "GigabitEthernet0/3"]
]

# Получить первый маршрут
first_route = routing_table[0]  # ["10.0.0.0/8", "192.168.1.1", "GigabitEthernet0/1"]

# Получить сеть первого маршрута
network = routing_table[0][0]   # "10.0.0.0/8"

# Получить интерфейс второго маршрута
interface = routing_table[1][2] # "GigabitEthernet0/2"
```

Конфигурация VLAN
```python
vlans = [
    [10, "Management", ["192.168.10.0/24"]],
    [20, "Users", ["192.168.20.0/24"]],
    [30, "Servers", ["192.168.30.0/24", "192.168.31.0/24"]]
]

# Получить информацию о VLAN 20
vlan20 = vlans[1]          # [20, "Users", ["192.168.20.0/24"]]
vlan_id = vlans[1][0]      # 20
vlan_name = vlans[1][1]    # "Users"
vlan_networks = vlans[1][2] # ["192.168.20.0/24"]
```

Матрица смежности (топология сети)
```python
# Связи между устройствами
# 1 = есть связь, 0 = нет связи
topology = [
    [0, 1, 1, 0],  # Router1
    [1, 0, 0, 1],  # Router2
    [1, 0, 0, 1],  # Switch1
    [0, 1, 1, 0]   # Switch2
]

# Проверить связь Router1 -> Router2
link = topology[0][1]  # 1 (есть связь)

# Проверить связь Router1 -> Switch2
link = topology[0][3]  # 0 (нет связи)
```

Изменение элементов
```python
# Изменить имя VLAN
vlans[1][1] = "Employees"

# Добавить сеть в VLAN
vlans[1][2].append("192.168.21.0/24")

# Добавить новый VLAN
vlans.append([40, "Guests", ["192.168.40.0/24"]])
```

📌 Итог

| Действие | Код |
|----------|-----|
| Создать | `nested = [[1,2], ["a","b"]]` |
| Получить внутренний список | `nested[0]` |
| Получить элемент внутри | `nested[0][1]` |
| Изменить элемент | `nested[0][0] = 99` |
| Добавить новый внутренний список | `nested.append([3,4])` |
