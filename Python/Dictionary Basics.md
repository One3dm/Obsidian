**Основы словарей (Dictionaries)**

Что такое словарь

**Словарь (dictionary)** — это коллекция **пар «ключ → значение»**.
```python
my_dict = {
    "rtr1": "10.100.1.1",
    "rtr2": "10.100.2.1",
    "rtr3": "10.100.3.1"
}
```

| Характеристика | Описание |
|----------------|----------|
| **Пары ключ-значение** | Каждый ключ связан со значением |
| **Упорядоченность** | С Python 3.7 сохраняется порядок вставки ключей |
| **Быстрый поиск** | O(1) — константное время доступа по ключу |
| **Изменяемость** | Можно добавлять, изменять, удалять пары |

> [!NOTE]
> В других языках словари называют **хешами (hashes)** или **хеш-таблицами (hash-maps)**.

---

## Доступ к значениям

### Через квадратные скобки `[]`

```python
my_dict["rtr3"]     # '10.100.3.1'
```

### Присвоение нового значения

```python
my_dict["rtr3"] = "10.100.100.1"   # изменить существующий
my_dict["rtr4"] = "10.100.4.1"    # добавить новый
```

---

## Ошибка при обращении к несуществующему ключу

Если ключа нет, Python выбрасывает исключение `KeyError`:

```python
my_dict["rtr5"]   # ❌ KeyError: 'rtr5'
```

---

## Метод `.get()` — безопасное получение значения

```python
# Если ключ существует — возвращает значение
my_dict.get("rtr3")   # '10.100.100.1'

# Если ключа нет — возвращает None (без ошибки)
ret_val = my_dict.get("rtr4")
print(ret_val)   # None

# Можно задать значение по умолчанию
my_dict.get("rtr4", "unknown")   # 'unknown'
```

---

## Сравнение способов доступа

| Метод | Поведение при отсутствии ключа |
|-------|-------------------------------|
| `my_dict[key]` | ❌ `KeyError` |
| `my_dict.get(key)` | ✅ возвращает `None` |
| `my_dict.get(key, default)` | ✅ возвращает `default` |

> [!TIP]
> Используйте `.get()` когда:
> - Не уверены, существует ли ключ
> - Не хотите обрабатывать исключение
> - Нужно значение по умолчанию

## 📌 Итог

```python
# Создание словаря
device = {
    "name": "rtr1",
    "ip": "10.100.1.1",
    "model": "Cisco 4321"
}

# Доступ
device["ip"]                 # '10.100.1.1'
device.get("name")           # 'rtr1'
device.get("location", "N/A") # 'N/A'

# Добавление/изменение
device["location"] = "NYC"   # новая пара
device["ip"] = "10.100.1.2"  # изменение

# Осторожно: несуществующий ключ
# device["os"]  # ❌ KeyError
```
