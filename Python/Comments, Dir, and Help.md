**Комментарии в коде и встроенные функции dir() и help()**

**Комментарии в коде**

Однострочные комментарии
```python
# Это комментарий - всё после решётки игнорируется Python
my_ip_addr = input("Enter an IP address: ")

# Эта строка выводит IP-адрес
print(my_ip_addr)

print("Hello again")  # Комментарий после кода (через 2 пробела)
```

### Многострочные комментарии
В Python нет специального синтаксиса для многострочных комментариев. Используйте несколько строк с `#`:
```python
# Если комментарий длинный,
# используйте несколько строк
# с символом решётки.
# Такой стиль рекомендуется PEP 8.
print(my_ip_addr)
```

### Специальные комментарии (практика)
```python
import os  # noqa: F401 - игнорировать предупреждение линтера
result = some_func()  # TODO: обработать случай None
# FIXME: временное решение, нужно переписать к 01.04.2024
# NOTE: важно для совместимости со старыми версиями протокола
# HACK: костыль для обхода бага в библиотеке
```

> [!WARNING]
> Тройные кавычки `"""` — это **не комментарий**, а многострочная строка (docstring). Хотя визуально похоже, это выполнимый код, который создаёт строковый объект. Используется для документации функций/классов.

## dir() — исследование объектов

`dir()` показывает все доступные методы и атрибуты объекта.

### С аргументом (объектом)
```python
my_str = "whatever"
dir(my_str)
```

Вывод (сокращённо):
```
['__add__', '__class__', '__contains__', 'capitalize', 'casefold', 
 'center', 'count', 'encode', 'endswith', 'find', 'format', 'index',
 'isalnum', 'isalpha', 'isdigit', 'islower', 'isupper', 'join', 
 'lower', 'lstrip', 'replace', 'rfind', 'split', 'strip', 'upper', ...]
```

### Без аргументов
`dir()` без аргументов показывает имена в текущей области видимости:
```python
x = 10
y = "text"
z = [1, 2, 3]
dir()  # покажет: ['__builtins__', '__doc__', '__name__', 'x', 'y', 'z', ...]
```

### Практическое использование для сетевой автоматизации
```python
# Исследование сетевых объектов
ip_address = "192.168.1.1"
print("Методы строки (IP-адреса):")
for method in dir(ip_address):
    if not method.startswith('__'):  # Пропустить служебные методы
        print(f"  {method}()")

# Пример: найти методы для проверки IP
# В выводе увидим: startswith(), endswith(), split(), isdigit() и т.д.
```

## help() — встроенная документация

`help()` показывает подробную документацию по методу, функции или объекту.

### Использование с методами
```python
my_str = "test"
help(my_str.upper)
```

Вывод:
```
Help on built-in function upper:

upper() method of builtins.str instance
    Return a copy of the string converted to uppercase.
```

### Использование с типами данных
```python
help(str)        # Документация по всему строковому типу
help(list)       # Документация по спискам
help(dict)       # Документация по словарям
```

### Интерактивный режим
```python
help()  # Вход в интерактивную справку

# Внутри интерактивной справки:
help> str.split    # Информация о методе split
help> modules      # Список всех модулей
help> keywords     # Список ключевых слов Python
help> q           # Выход (quit)
```

## Практический workflow исследования в REPL

**Типичная последовательность изучения нового объекта:**

```python
# 1. Создаём объект для изучения
>>> ip = "192.168.1.1"

# 2. Узнаём тип объекта
>>> type(ip)
<class 'str'>

# 3. Смотрим все доступные методы
>>> dir(ip)
[... 'split', 'startswith', 'strip', 'upper' ...]

# 4. Выбираем интересный метод и читаем документацию
>>> help(ip.split)
Help on built-in function split:
split(sep=None, maxsplit=-1) method of builtins.str instance
    Return a list of the words in the string, using sep as the delimiter...

# 5. Пробуем использовать метод
>>> ip.split('.')
['192', '168', '1', '1']

# 6. Ищем похожие методы
>>> [m for m in dir(ip) if 'split' in m]
['rsplit', 'split', 'splitlines']
```

### Пример для сетевых данных
```python
# Исследуем, как работать с IP-адресами
>>> ip = "192.168.1.1/24"
>>> dir(ip)
# Видим методы: split(), partition(), startswith(), endswith()

>>> help(ip.partition)
# Узнаём, что partition() разбивает строку по разделителю

>>> ip.partition('/')
('192.168.1.1', '/', '24')  # Отделили адрес от маски

>>> network, _, mask = ip.partition('/')
>>> network
'192.168.1.1'
```

## 📌 Итог

| Функция/Синтаксис | Что делает | Когда использовать |
|------------------|-----------|-------------------|
| `# комментарий` | Однострочный комментарий | Объяснение сложного кода, отключение строк |
| `# TODO: текст` | Отметка для доработки | Отслеживание задач в коде |
| `# FIXME: текст` | Отметка об ошибке | Пометить временные решения |
| `dir(obj)` | Показывает методы объекта | Исследование нового объекта или типа |
| `dir()` | Показывает локальные переменные | Отладка, что доступно в области видимости |
| `help(obj)` | Документация по объекту | Понимание как работает метод/функция |
| `help()` | Интерактивная справка | Изучение Python в REPL |

### Ключевые принципы:
1. **Комментарии объясняют "почему", а не "что"** — код должен быть самодокументируемым
2. **Используйте `dir()` для открытия** — не запоминайте все методы, исследуйте их
3. **`help()` — ваша документация** — всегда под рукой, даже без интернета
4. **Исследуйте цепочкой** `type() → dir() → help() → пробуем`

### Пример для сетевого инженера:
```python
# Быстрое исследование сетевого модуля
>>> import ipaddress
>>> dir(ipaddress)
>>> help(ipaddress.IPv4Network)
>>> network = ipaddress.IPv4Network('192.168.1.0/24')
>>> dir(network)
>>> help(network.hosts)
```

> [!TIP]
> Сочетание `dir()` и `help()` — самый быстрый способ стать самостоятельным в Python. Вместо поиска в Google, сначала проверяйте встроенную документацию.
```
