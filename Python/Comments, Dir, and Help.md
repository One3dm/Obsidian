**Комментарии в коде**

Однострочные комментарии
```python
# Это комментарий
my_ip_addr = input("Enter an IP address: ")

# Эта строка выводит IP-адрес
print(my_ip_addr)

print("Hello again")  # Комментарий после кода
```

Многострочные комментарии
В Python нет специального синтаксиса для многострочных комментариев. Используйте несколько строк с `#`:
```python
# Если комментарий длинный,
# используйте несколько строк
# с символом #
print(my_ip_addr)
```

> [!NOTE]
> Тройные кавычки `"""` — это не комментарий, а многострочная строка (docstring). Хотя часто используется для документации.

**dir() — список методов и атрибутов**

`dir()` показывает все доступные методы и атрибуты объекта.

```python
my_str = "whatever"
dir(my_str)
```

Вывод (сокращённо):
```
['__add__', '__class__', '__contains__', 'capitalize', 'casefold', 'center', 'count', 'encode', 'endswith', 'find', 'format', 'index', 'isalnum', 'isalpha', 'isdigit', 'islower', 'isupper', 'join', 'lower', 'lstrip', 'replace', 'rfind', 'split', 'strip', 'upper', ...]
```

Пример с переменной:
```python
my_var = "a string"
dir(my_var)   # показывает всё, что можно делать со строкой
```

**help() — документация**

`help()` показывает подробную документацию по методу или объекту.
```python
help(my_str.upper)
```

Вывод:
```
Help on built-in function upper:

upper() method of builtins.str instance
    Return a copy of the string converted to uppercase.
```

Использование:
- `help(str)` — документация по типу `str`
- `help(my_str.upper)` — документация по методу `upper()`
- `help()` — интерактивная справка (выход — `q`)

📌 Итог

| Функция | Что делает | Пример |
|---------|-----------|--------|
| `#` | Комментарий (не выполняется) | `# пояснение` |
| `dir()` | Показывает методы и атрибуты | `dir(my_var)` |
| `help()` | Показывает документацию | `help(my_var.upper)` |

> [!TIP]
> `dir()` и `help()` — лучшие друзья начинающего Python-разработчика. Не запоминайте все методы, просто смотрите их через `dir()` и читайте документацию через `help()`.
