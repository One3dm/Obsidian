# Специальные имена (Special Names)

## 1. "Приватные" атрибуты (один подчёркивание в начале)

```python
class NetDevice:
    def __init__(self, device_type, host, username, password):
        self._username = username   # "приватный" атрибут
        self._password = password
```

- **Соглашение:** одно подчёркивание `_` в начале имени означает **"не трогай меня снаружи"**
- Это **не безопасность**, а **программное намерение** (convention)
- Снаружи доступ есть, но не рекомендуется

```python
nd = NetDevice(...)
print(nd._username)   # 'admin' — доступ есть, но так делать не стоит
```

## 2. Name Mangling (два подчёркивания в начале)

```python
class NetDevice:
    def __init__(self, device_type, ...):
        self.__device_type = device_type   # name mangling
```

**Что происходит:** Python **автоматически переименовывает** атрибут в `_ClassName__attribute`

```python
nd = NetDevice(device_type="cisco_ios", ...)

# Обычный доступ не работает
nd.__device_type        # ❌ AttributeError

# Но через изменённое имя — можно
nd._NetDevice__device_type   # 'cisco_ios'
```

> [!NOTE]
> Kirk говорит: "Name mangling — странная штука, я никогда не использовал её на практике. Её цель — показать создателю подкласса, что этот атрибут не стоит переопределять."

## 3. Магические методы (dunder methods)

Это методы с **двумя подчёркиваниями в начале и в конце** (double underscore `__method__`). Они имеют особое значение в Python и вызываются автоматически.

```python
class NetDevice:
    def __init__(self, ...):          # dunder-init
        ...

    def __str__(self):                # dunder-str
        return f"NetDevice Object {self.host}:{self.port}"
```

**Вызов:**

```python
nd = NetDevice(...)
print(nd)   # автоматически вызывается __str__
```

**Примеры магических методов:**

| Метод | Когда вызывается |
|-------|------------------|
| `__init__(self, ...)` | При создании объекта |
| `__str__(self)` | При `print(объект)` или `str(объект)` |
| `__repr__(self)` | При `repr(объект)` |
| `__len__(self)` | При `len(объект)` |
| `__getitem__(self, key)` | При `объект[key]` |

## 📌 Итог

| Конструкция | Название | Назначение |
|-------------|----------|------------|
| `_attr` | "Приватный" атрибут | Соглашение: не используй снаружи |
| `__attr` | Name mangling | Автоматическое переименование (редко нужно) |
| `__method__` | Магический метод | Специальные методы, вызываемые автоматически |

```python
class MyClass:
    def __init__(self, value):
        self._private = value       # приватный по соглашению
        self.__mangled = value      # name mangling

    def __str__(self):
        return f"MyClass: {self._private}"
```
