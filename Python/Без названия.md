# Циклы и словари

При работе со словарями часто нужно перебирать их содержимое. Вот три основных способа.

---

## 1. Перебор ключей (по умолчанию)

Когда вы просто пишете `for key in my_dict:`, вы перебираете **ключи** словаря.

```python
my_dict = {
    "rtr1": "10.100.1.1",
    "rtr2": "10.100.2.1",
    "rtr3": "10.100.100.1"
}

for k in my_dict:
    print(k)
```

Вывод:
```
rtr1
rtr2
rtr3
```

> [!NOTE]
> Это краткая форма для `for k in my_dict.keys():`.

---

## 2. Перебор значений — `.values()`

Метод `.values()` возвращает все **значения** словаря.

```python
for v in my_dict.values():
    print(v)
```

Вывод:
```
10.100.1.1
10.100.2.1
10.100.100.1
```

---

## 3. Перебор пар «ключ-значение» — `.items()`

Метод `.items()` возвращает **пары** (кортежи) `(ключ, значение)`. Чаще всего используется с распаковкой.

```python
for k, v in my_dict.items():
    print(f"{k} --> {v}")
```

Вывод:
```
rtr1 --> 10.100.1.1
rtr2 --> 10.100.2.1
rtr3 --> 10.100.100.1
```

> [!TIP]
> Это **самый распространённый** способ, когда нужны и ключи, и значения.

---

## Сводная таблица

| Метод | Что возвращает | Тип в цикле | Когда использовать |
|-------|----------------|-------------|---------------------|
| `for k in dict:` | Ключи | скаляр | Только ключи |
| `.values()` | Значения | скаляр | Только значения |
| `.items()` | Пары (ключ, значение) | кортеж или распаковка `k, v` | Нужны и ключи, и значения |

---

## 📌 Итог

```python
# Ключи
for key in my_dict:
    print(key)

# Значения
for value in my_dict.values():
    print(value)

# Ключи и значения (распаковка)
for key, value in my_dict.items():
    print(f"{key} -> {value}")
```
