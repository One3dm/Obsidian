**Статические методы (Static Methods)**

Что такое статический метод

Статический метод — это метод внутри класса, который **не использует `self`** и помечается декоратором `@staticmethod`.

```python
class MyClass:
    @staticmethod
    def my_method(arg1="Hello World!"):
        print(arg1)
```

- Нет параметра `self`
- Работает как обычная функция, но **организационно принадлежит классу**

> [!NOTE]
> Декоратор `@staticmethod` — это специальный модификатор, который меняет поведение метода.


Когда может понадобиться статический метод

Есть действие, **связанное с классом**, но для него **не нужен объект** (не нужны атрибуты экземпляра).

**Варианты реализации:**

| Вариант | Описание |
|---------|----------|
| 1. Обычная функция | Вне класса |
| 2. Обычный метод | С `self`, но `self` не используется |
| 3. Статический метод | Без `self`, внутри класса |


Почему выбирают статический метод вместо обычного метода?

1. **Чистота кода** — зачем писать `self`, если он не используется?
2. **Немного меньше ресурсов** — не нужно передавать ссылку на объект

```python
# ❌ Обычный метод с неиспользуемым self
class MyClass:
    def do_something(self, param):
        print("Hello World")

# ✅ Статический метод
class MyClass:
    @staticmethod
    def do_something(param):
        print("Hello World")
```


Почему не использовать обычную функцию вне класса?

Иногда статический метод нужен, чтобы:

1. **Использовать иерархию наследования** — статический метод можно переопределить в дочерних классах (обычную функцию — нет)
2. **Организовать код** — логически сгруппировать связанные действия внутри класса

Пример из библиотеки Netmiko

```python
class BaseFileTransfer:
    @staticmethod
    def process_md5(md5_output, pattern=r"=\s+(.*)"):
        """
        Извлекает MD5-хеш из вывода команды.
        Для Cisco IOS работает по умолчанию.
        Другие вендоры могут переопределить этот метод.
        """
        match = re.search(pattern, md5_output)
        if match:
            return match.group(1)
        raise ValueError(f"Invalid output: {md5_output}")
```

- Поведение по умолчанию — для Cisco
- Другие вендоры могут **переопределить** этот метод в своих классах


Сравнение подходов

| Характеристика | Обычная функция | Обычный метод | Статический метод |
|----------------|----------------|---------------|-------------------|
| Где находится | Вне класса | Внутри класса | Внутри класса |
| Есть `self` | Нет | Да | Нет |
| Можно переопределить в наследнике | ❌ | ✅ | ✅ |
| Логическая группировка | ❌ | ✅ | ✅ |


📌 Итог

```python
class MyClass:
    @staticmethod
    def helper_function(value):
        return value * 2

# Вызов (без создания объекта)
result = MyClass.helper_function(21)  # 42
```

> [!TIP]
- Используйте **статический метод**, когда действие логически относится к классу, но не требует доступа к атрибутам объекта
- Если действие не связано с классом — используйте **обычную функцию**
- Если нужно переопределение в наследниках — статический метод подходит
