**Передача аргументов с помощью `**kwargs`**

Проблема

У нас есть словарь, в котором ключи совпадают с именами параметров функции. Как передать содержимое словаря в качестве **именованных аргументов**?

```python
def print_ips(ip_addr1, ip_addr2):
    print(f"{ip_addr1=}")
    print(f"{ip_addr2=}")

ips = {
    "ip_addr1": "192.168.100.1",
    "ip_addr2": "192.168.100.2",
}
```



❌ Неправильно: передача словаря целиком

```python
print_ips(ips)
```

Весь словарь передаётся как один аргумент (в `ip_addr1`). Это не то, что нам нужно.


❌ `*ips` — передача только ключей

```python
print_ips(*ips)   # передаст "ip_addr1", "ip_addr2"
```

Звёздочка `*` распаковывает только **ключи** словаря.


✅ Правильно: `**ips` — распаковка ключей и значений

Две звёздочки `**` перед словарём в **вызове функции** означают: "передай пары **ключ → значение** как **именованные аргументы**".

```python
print_ips(**ips)
```

- `ip_addr1="192.168.100.1"`
- `ip_addr2="192.168.100.2"`

**Условие:** ключи словаря должны **точно совпадать** с именами параметров функции.


Сравнение

| Код | Что передаётся |
|-----|----------------|
| `print_ips(ips)` | Один аргумент — словарь |
| `print_ips(*ips)` | Ключи словаря как позиционные аргументы |
| `print_ips(**ips)` | Пары ключ-значение как именованные аргументы |

Пример вывода

```bash
$ python kwargs.py
ip_addr1='192.168.100.1'
ip_addr2='192.168.100.2'
```


📌 Итог

```python
# ** в вызове функции — распаковка словаря в именованные аргументы
def my_func(a, b, c):
    pass

my_dict = {"a": 1, "b": 2, "c": 3}
my_func(**my_dict)   # a=1, b=2, c=3
```
