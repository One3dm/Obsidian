**Соглашения об именовании в Python**

Это не жёсткие правила, а **общепринятые конвенции** (PEP 8), которых следует придерживаться для читаемости кода.

**Основные стили**

| Стиль                         | Пример                           | Где используется                                |
| ----------------------------- | -------------------------------- | ----------------------------------------------- |
| `snake_case_lower`            | `my_variable`, `calculate_sum()` | Переменные и функции                            |
| `PascalCase`                  | `MyClass`, `UserAccount`         | Имена классов                                   |
| `SNAKE_CASE_UPPER`            | `MAX_SIZE`, `API_KEY`            | Константы (неизменяемые значения)               |
| `self`                        | `self.name`                      | Ссылка на экземпляр класса (в методах)          |
| `_` (одиночное подчёркивание) | `_`, `_temp`                     | «Мусорная» переменная (не будет использоваться) |

**Подробнее**
snake_case_lower — переменные и функции
```python
my_ip_address = "10.220.107.99"
def get_device_name():
    return "router1"
```
Можно использовать цифры, но **не в начале**:
```python
var9 = 42      # ✅
9var = 42      # ❌ SyntaxError
```

### 2. `PascalCase` — классы
```python
class NetworkDevice:
    pass

class UserSession:
    pass
```

### 3. `SNAKE_CASE_UPPER` — константы
```python
MAX_RETRIES = 5
DEFAULT_TIMEOUT = 30
API_ENDPOINT = "https://api.example.com"
```

### 4. `self` — в методах классов
```python
class Device:
    def __init__(self, ip):
        self.ip = ip    # self ссылается на текущий объект
```

### 5. `_` (одиночное подчёркивание) — «мусорная» переменная
Используется, когда значение не нужно:
```python
for _ in range(5):
    print("Hello")   # просто повторить 5 раз

_, b, _ = (1, 2, 3)  # b = 2, остальные игнорируем
```

---

## 📌 Итог

| Для чего | Стиль | Пример |
|----------|-------|--------|
| Переменные и функции | `snake_case` | `my_var`, `get_data()` |
| Классы | `PascalCase` | `MyClass` |
| Константы | `UPPER_CASE` | `MAX_LIMIT` |
| Ссылка на объект | `self` | `self.value` |
| Ненужное значение | `_` | `for _ in range(10)` |
