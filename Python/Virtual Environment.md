**Виртуальное окружение (venv)**

**Виртуальное окружение** — изолированная среда Python с собственными пакетами и интерпретатором.

Преимущества (песочница):
- Разные проекты используют разные версии библиотек
- Нет конфликтов зависимостей
- Не нужно прав администратора для установки пакетов
- Чистота глобального Python

# Создание и активация

## macOS / Linux

```bash
# Создать виртуальное окружение 
python3 -m venv venv 

# Активировать 
source venv/bin/activate 

# После активации в терминале появляется (venv)
```

# Windows

```cmd
# Создать виртуальное окружение
python -m venv venv

# Активировать
venv\Scripts\activate

# После активации в терминале появляется (venv)
```

**Проверка**
После активации:
```bash
# Показать путь к Python (должен указывать на venv)
which python    # Linux/macOS
where python    # Windows

# Версия Python
python --version
```

**Деактивация**
```bash
deactivate
```

Команды для запоминания

| Действие | macOS / Linux | Windows |
|----------|---------------|---------|
| Создать | `python3 -m venv имя_venv` | `py -m venv имя_venv` |
| Активировать | `source имя_venv/bin/activate` | `имя_venv\Scripts\activate` |
| Деактивировать | `deactivate` | `deactivate` |
