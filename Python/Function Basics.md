Основы функций

Зачем нужны функции

- **Повторное использование кода** — написали один раз, используем много раз
- **Создание строительных блоков** для решения различных задач


Синтаксис функции
```python
def my_func(arg1, arg2, arg3=None):
    print("This is a function")
    print(f"arg1 value --> {arg1}")
    return arg1 + arg2
```

| Элемент | Описание |
|---------|----------|
| `def` | Ключевое слово для определения функции |
| `my_func` | Имя функции |
| `(arg1, arg2, arg3=None)` | Параметры (переменные, локальные для функции) |
| `:` | Двоеточие, завершающее определение |
| Блок с отступом | Тело функции (что она делает) |
| `return` | Возвращает значение (если нет `return` — возвращает `None`) |


Вызов функции

```python
# Вызов функции
my_func(22, 33)
```

`22` и `33` — это **аргументы**, которые передаются в функцию.


📌 Итог

| Термин | Значение |
|--------|----------|
| `def` | Определение функции |
| Параметры | Переменные в определении функции |
| Аргументы | Значения, передаваемые при вызове |
| `return` | Возвращаемое значение |
