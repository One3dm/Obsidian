**Словари изменяемы (Mutable)**

Как и списки, словари в Python являются **изменяемыми** объектами.

Что это значит

- Можно добавлять, изменять и удалять пары «ключ-значение» **без создания нового объекта**
- При присваивании `b = a` обе переменные ссылаются на **один и тот же словарь**


Пример: присваивание не создаёт копию
```python
routers = {
    "rtr1": "10.100.1.1",
    "rtr2": "10.100.2.1",
    "rtr3": "10.100.100.1"
}

ca_routers = routers          # ca_routers и routers — один и тот же объект
ca_routers is routers         # True
```

Если изменить `ca_routers`, изменения затронут и `routers`:

```python
ca_routers["rtr4"] = "10.200.1.1"
print(routers)                # новый ключ появится и здесь
```


Копирование словарей

Чтобы создать независимую копию, используйте:

| Метод | Тип копии |
|-------|-----------|
| `.copy()` | Мелкая (shallow) |
| `dict(other_dict)` | Мелкая (shallow) |
| `copy.deepcopy()` | Глубокая (deep) |

```python
# Мелкая копия
new_dict = routers.copy()

# Глубокая копия (для вложенных изменяемых объектов)
import copy
new_dict = copy.deepcopy(routers)
```

Сравнение с неизменяемыми типами

| Тип | Изменяемый? | При `b = a` |
|-----|-------------|-------------|
| `int`, `str`, `tuple` | ❌ | отдельные объекты |
| `list`, `dict`, `set` | ✅ | ссылка на тот же объект |

📌 Итог

```python
# Словари изменяемы
my_dict = {"a": 1, "b": 2}
my_dict["c"] = 3          # изменяем исходный объект

# Присваивание не копирует
dict2 = my_dict
dict2 is my_dict          # True

# Копирование
dict3 = my_dict.copy()
dict3 is my_dict          # False
```

> [!WARNING]
> Все концепции изменяемости, с которыми вы познакомились на примере списков (мелкая копия, глубокая копия, присваивание), полностью применимы и к словарям.
