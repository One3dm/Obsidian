
f-строки в Python

Буква `f` (от **f**ormatted) превращает обычную строку в **f-строку** — специальную строку, где содержимое внутри `{}` выполняется как код Python.

Без `f` vs С `f`

```python
# БЕЗ f - обычная строка (фигурные скобки как текст)
name = "Router1"
text = "Device: {name}"
print(text)  # Device: {name}

# С f - f-строка (значение подставляется)
name = "Router1"
text = f"Device: {name}"
print(text)  # Device: Router1
```

**Золотое правило:** Если в строке есть `{}` и нужно подставить значения — **всегда начинай с `f`**.

**Частая ошибка:**
```python
# ❌ ЗАБЫЛИ f
ip = "10.0.0.1"
command = "ping {ip}"  # Будет: ping {ip}

# ✅ ПОМНИЛИ про f
ip = "10.0.0.1"
command = f"ping {ip}"  # Будет: ping 10.0.0.1
```

Базовый синтаксис
f-строки позволяют встраивать переменные и выражения прямо в строку:
```python
ip_addr1 = "10.220.89.17"
print(f"IP-адрес: {ip_addr1}")
# IP-адрес: 10.220.89.17
```

Внутри `{}` можно писать выражения:
```python
print(f"2 + 17 = {2 + 17}")
# 2 + 17 = 19

print(f"Первый октет: {ip_addr1.split('.')[0]}")
# Первый октет: 10
```

Форматирование колонок

Выравнивание по ширине
```python
ip_addr1 = "10.220.89.17"
ip_addr2 = "192.168.10.1"
ip_addr3 = "172.31.1.9"

# Ширина 20 символов (по умолчанию выравнивание влево)
print(f"{ip_addr1:20}{ip_addr2:20}{ip_addr3:20}")

# Выравнивание вправо
print(f"{ip_addr1:>20}{ip_addr2:>20}{ip_addr3:>20}")

# Выравнивание по центру
print(f"{ip_addr1:^20}{ip_addr2:^20}{ip_addr3:^20}")
```

Пример с заголовками
```python
header = "_" * 20
header1, header2, header3 = "ip_addr1", "ip_addr2", "ip_addr3"

print(f"{header1:^20} {header2:^20} {header3:^20}")
print(f"{header:^20} {header:^20} {header:^20}")
print(f"{ip_addr1:^20} {ip_addr2:^20} {ip_addr3:^20}")
```

Форматирование чисел (float)
```python
my_var = 1/3      # 0.3333333333333333
f"Значение: {my_var:.2f}"   # 'Значение: 0.33'
```

Формат: `{переменная:.Nf}` — N знаков после запятой.

**Практический пример для сетевых данных:**
```python
bandwidth = 1000 * 0.85  # 850 Mbps
packet_loss = 0.034567   # 3.4567%

print(f"Пропускная способность: {bandwidth:.0f} Mbps")
# Пропускная способность: 850 Mbps

print(f"Потери пакетов: {packet_loss:.2%}")
# Потери пакетов: 3.46%
```

Полезные трюки
Отладка: `{переменная = }` (Python 3.8+)
```python
my_var = "hello"
f"{my_var = }"    # "my_var = 'hello'"

# Практическое использование для отладки
device = "Router1"
ip = "192.168.1.1"
print(f"{device = }, {ip = }")
# device = 'Router1', ip = '192.168.1.1'
```

Представление (`repr`)
```python
f"repr: {my_var!r}"   # "repr: 'hello'"
```

Форматирование дат
```python
from datetime import datetime
now = datetime.now()
f"Дата: {now:%B %d, %Y}"   # 'Дата: November 18, 2022'
```

Многострочные f-строки
```python
hostname = "SW-01"
ip = "192.168.1.1"
mask = "255.255.255.0"

config = f"""
hostname {hostname}
!
interface vlan1
 ip address {ip} {mask}
!
"""
```

Конфликт кавычек
Если f-строка в **двойных** кавычках — внутри используйте **одинарные**:
```python
my_dict = {"ip_addr": "8.8.8.8"}

# ❌ Ошибка — двойные кавычки внутри двойных
f"IP: {my_dict["ip_addr"]}"

# ✅ Правильно
f"IP: {my_dict['ip_addr']}"   # 'IP: 8.8.8.8'

# ✅ Или поменять внешние кавычки
f'IP: {my_dict["ip_addr"]}'   # 'IP: 8.8.8.8'
```

Практические примеры для сетевой автоматизации
```python
# 1. Формирование команд
interface = "GigabitEthernet0/1"
vlan = 100
command = f"interface {interface}\nswitchport access vlan {vlan}"

# 2. Создание отчётов
devices = ["R1", "R2", "R3", "R4"]
online = 3
report = f"""
Отчёт о доступности:
Всего устройств: {len(devices)}
Доступно: {online}
Процент доступности: {(online/len(devices))*100:.1f}%
"""

# 3. Форматирование таблицы вывода
print(f"{'Device':<15}{'IP':<20}{'Status':<10}")
print(f"{'-'*15:<15}{'-'*20:<20}{'-'*10:<10}")
print(f"{'Router1':<15}{'192.168.1.1':<20}{'UP':<10}")
print(f"{'Switch1':<15}{'10.0.0.1':<20}{'DOWN':<10}")
```

Спецификаторы форматирования

| Спецификатор | Значение | Пример | Результат |
|--------------|----------|--------|-----------|
| `:N` | Ширина N (влево) | `f"{'text':10}"` | `'text      '` |
| `:>N` | Выравнивание вправо | `f"{'text':>10}"` | `'      text'` |
| `:^N` | Выравнивание по центру | `f"{'text':^10}"` | `'   text   '` |
| `:.Nf` | N знаков после запятой | `f"{3.14159:.2f}"` | `'3.14'` |
| `:.N%` | Проценты с N знаками | `f"{0.0345:.2%}"` | `'3.45%'` |
| `!r` | repr() представление | `f"{'text'!r}"` | `"'text'"` |
| `{var = }` | Отладка (Python 3.8+) | `f"{ip = }"` | `"ip = '192.168.1.1'"` |

📌 Итог
```python
# Основы
f"Текст {переменная}"

# Форматирование
f"{ip:^20}"      # центрирование
f"{value:.2f}"   # 2 знака после запятой

# Отладка
f"{var = }"      # var = 'значение'

# Кавычки
f"Внешние 'внутренние'"  # двойные снаружи — одинарные внутри
f'Внешние "внутренние"'  # одинарные снаружи — двойные внутри
```

**Правила использования:**
1. **Всегда используйте f-строки** для Python 3.6+
2. **Не забывайте букву `f`** перед кавычками
3. **Сложные выражения выносите** в переменные для читаемости
4. **Используйте форматирование** для красивого вывода таблиц
5. **Для отладки** используйте `{var = }` (Python 3.8+)
