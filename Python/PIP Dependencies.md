**PIP** — менеджер пакетов Python
Устанавливает и управляет сторонними библиотеками.

**Обновление самого PIP**
- pip устанавливается автоматически при создании venv
- **Не обновляйте pip без необходимости** — это может вызвать проблемы

**Проверка текущей версии:**
```bash
pip --version
# Если версия старше 21.x (2021 год), стоит обновить
```

Если при установке пакета возникает ошибка о старой версии pip, тогда обновите:
```bash
# Стандартный способ
pip install --upgrade pip

# Более надежный способ (особенно на Windows)
python -m pip install --upgrade pip
```

**Основные команды PIP**

| Команда                            | Назначение                         |
| ---------------------------------- | ---------------------------------- |
| `pip install <package>`            | Установить пакет                   |
| `pip install <package>==<version>` | Установить конкретную версию       |
| `pip install -r requirements.txt`  | Установить все пакеты из файла     |
| `pip list`                         | Показать установленные пакеты      |
| `pip uninstall <package>`          | Удалить пакет                      |
| `pip freeze > requirements.txt`    | **Сохранить зависимости в файл**   |
| `pip show <package>`               | **Показать информацию о пакете**   |
| `pip install --upgrade <package>`  | Обновить пакет до последней версии |

**Проверка установленных пакетов:**
```bash
pip list
```

Пример вывода:
```
Package    Version
pip        22.3.1
setuptools 65.5.0
```

**📁 requirements.txt — файл зависимостей**

**Создать файл со списком всех пакетов проекта:**
```bash
pip freeze > requirements.txt
```

**Установить все зависимости из файла:**
```bash
pip install -r requirements.txt
```

**Пример содержимого requirements.txt:**
```
netmiko==4.1.0
napalm==4.1.0
requests>=2.28.0  # минимальная версия
paramiko~=3.0.0   # совместимая версия (3.0.x)
```

**Полезные флаги**

```bash
# Установить пакет для разработки (включая зависимости для тестов)
pip install -e .

# Игнорировать установленные пакеты (принудительная переустановка)
pip install --force-reinstall <package>

# Установить пакет без зависимостей
pip install --no-deps <package>
```
