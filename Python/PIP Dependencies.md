PIP — менеджер пакетов Python. Устанавливает и управляет сторонними библиотеками.

**Обновление самого PIP**
- pip устанавливается автоматически при создании venv 
- Не обновляйте pip без необходимости — это может вызвать проблемы 

 Если при установке пакета возникает ошибка старой версии pip, тогда обновите:
```bash
# Стандартный способ pip install 
--upgrade pip 

# Более надежный способ (особенно на Windows) 
python -m pip install --upgrade pip
```

Проверка:
```bash
pip --version
```

Проверка версии:
```bash
pip list
```

Результат:
```
Package    Version
pip        22.3.1
setuptools 65.5.0
```

 **Основные команды PIP**

| Команда | Назначение |
|---------|------------|
| `pip install <package>` | Установить пакет |
| `pip install <package>==<version>` | Установить конкретную версию |
| `pip list` | Показать установленные пакеты |
| `pip uninstall <package>` | Удалить пакет |
| `pip freeze` | Вывести список пакетов (для requirements.txt) |
