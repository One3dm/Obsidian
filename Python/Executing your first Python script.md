**Создание и запуск скриптов Python**

**Создание файла**

Создайте файл с расширением `.py`, например `my_code.py`:
```python
my_ip_addr = input("Enter an IP address: ")
print(my_ip_addr)
```

**Имена файлов:**
- Используйте `snake_case`: `backup_config.py`, `get_interfaces.py`
- Избегайте пробелов и спецсимволов
- Расширение должно быть `.py`

Запуск скрипта

**Базовый способ (все платформы)**
```bash
python my_code.py
```

Пример:
```
$ python my_code.py
Enter an IP address: 10.17.88.10
10.17.88.10
```

**Альтернативные команды запуска**
```bash
python3 my_code.py      # Явно Python 3 (Linux/macOS)
py my_code.py           # Windows Python launcher
python -m my_code       # Запуск как модуль (без .py)
```

**Запуск из разных директорий**
```bash
 Абсолютный путь
python /home/user/scripts/my_code.py

# Относительный путь
python ../network_scripts/my_code.py
cd scripts && python my_code.py
```

**Shebang (macOS / Linux)**

Добавьте в **первую строку** файла:
```python
#!/usr/bin/env python
# или явно для Python 3:
#!/usr/bin/env python3

my_ip_addr = input("Enter an IP address: ")
print(my_ip_addr)
```

Сделайте файл исполняемым:
```bash
chmod +x my_code.py    # Добавить права на выполнение
chmod 755 my_code.py   # Альтернативный вариант
```

Теперь можно запускать напрямую:
```bash
./my_code.py
```

Комментарии в коде
```python
#!/usr/bin/env python

# Это однострочный комментарий - поясняет следующую строку
my_ip_addr = input("Enter an IP address: ")

"""
Это многострочный комментарий (docstring).
Используется для документации модулей, функций, классов.
Может занимать несколько строк.
"""

# Комментарии полезны для:
# 1. Объяснения сложной логики
# 2. Отключения кода при отладке
# 3. Описания назначения функции

print(my_ip_addr)  # Выводим введённый IP-адрес
```

Практические примеры для сетевой автоматизации

**Пример 1: Простой скрипт для ввода IP**
```python
#!/usr/bin/env python3
# get_ip.py - запрос IP-адреса у пользователя

device_ip = input("Введите IP-адрес устройства: ")
print(f"Подключаюсь к {device_ip}...")
# Дальше может быть код подключения через Netmiko
```

**Пример 2: Скрипт с аргументами командной строки**
```python
#!/usr/bin/env python3
import sys

if len(sys.argv) > 1:
    device_ip = sys.argv[1]  # Первый аргумент
else:
    device_ip = input("Введите IP-адрес: ")

print(f"IP: {device_ip}")
```
Запуск: `python script.py 192.168.1.1`

Простейшая отладка
```bash
# Запуск с флагом -i (интерактивный режим после выполнения)
python -i my_code.py
# После выполнения останетесь в REPL с переменными

# Проверка синтаксиса без запуска
python -m py_compile my_code.py

# Подробный вывод ошибок
python -v my_code.py    # Флаг -v показывает импорты
```

Распространённые ошибки новичков

**Файл не найден**
   ```bash
   # Ошибка: python: can't open file 'my_code.py'
   # Решение: проверьте путь и имя файла
   ls -la my_code.py    # Существует ли файл?
   pwd                  # В какой директории вы находитесь?
   ```

**Permission denied (Linux/macOS):**

```Bash
Ошибка: bash: ./my_code.py: Permission denied
chmod +x my_code.py  # Добавьте права на выполнение
```


Shebang не работает:**
   - Убедитесь, что shebang в первой строке
   - Проверьте, что после shebang нет пробелов
   - Убедитесь, что Python установлен и доступен по пути

📌 Итог

| Способ запуска | Команда | Когда использовать |
|----------------|---------|-------------------|
| Базовый | `python my_code.py` | Основной способ, работает везде |
| Явно Python 3 | `python3 my_code.py` | Если есть конфликт с Python 2 |
| Как модуль | `python -m my_code` | Более явный путь, без `.py` |
| Прямой (Linux/macOS) | `./my_code.py` | Только с shebang и `chmod +x` |
| С аргументами | `python script.py arg1 arg2` | Передача параметров в скрипт |

**Ключевые моменты:**
1. Всегда используйте расширение `.py`
2. Shebang (`#!/usr/bin/env python3`) нужен только для прямого запуска на Linux/macOS
3. `chmod +x` требуется для прямого запуска `./script.py`
4. На Windows используйте `python script.py` (shebang игнорируется)
5. Комментарии помогают понять код вам и другим
