Использование `*args` и `**kwargs` в определении функций

`*args` — любое количество позиционных аргументов

Если поставить `*args` в **определении функции**, функция сможет принимать **любое количество позиционных аргументов**.

```python
def print_ips(*args):
    """Принимает любое количество позиционных аргументов."""
    print(type(args))   # <class 'tuple'>
    print(args)

print_ips("10.1.1.1", "10.1.1.2", "10.1.1.3")
```

Вывод:
```
<class 'tuple'>
('10.1.1.1', '10.1.1.2', '10.1.1.3')
```

Все переданные аргументы собираются в **кортеж** `args`.


`**kwargs` — любое количество именованных аргументов

Если поставить `**kwargs` в **определении функции**, функция сможет принимать **любое количество именованных аргументов**.

```python
def print_ips(**kwargs):
    """Принимает любое количество именованных аргументов."""
    print(type(kwargs))   # <class 'dict'>
    print(kwargs)

print_ips(
    ip_addr1="192.168.100.1",
    ip_addr2="192.168.100.2",
    ip_addr3="192.168.100.3"
)
```

Вывод:
```
<class 'dict'>
{
    'ip_addr1': '192.168.100.1',
    'ip_addr2': '192.168.100.2',
    'ip_addr3': '192.168.100.3'
}
```

Все переданные именованные аргументы собираются в **словарь** `kwargs`.



Сравнение: вызов vs определение

| | `*args` | `**kwargs` |
|--|---------|------------|
| **В вызове функции** | Распаковка списка/кортежа в позиционные аргументы | Распаковка словаря в именованные аргументы |
| **В определении функции** | Сбор позиционных аргументов в кортеж | Сбор именованных аргументов в словарь |

📌 Итог

```python
# В определении функции
def func(*args, **kwargs):
    print("Positional (tuple):", args)
    print("Keyword (dict):", kwargs)

# В вызове
func(1, 2, 3, a="hello", b="world")
```

Вывод:
```
Positional (tuple): (1, 2, 3)
Keyword (dict): {'a': 'hello', 'b': 'world'}
```

> [!NOTE]
> Имена `args` и `kwargs` — это **соглашение**, но звёздочки (`*` и `**`) обязательны.
