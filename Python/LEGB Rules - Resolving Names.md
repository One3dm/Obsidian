Правило LEGB — поиск имён в функциях

Python ищет переменные в следующем порядке: **L → E → G → B**

| Уровень | Название | Что это |
|---------|----------|---------|
| **L** | Local | Переменные, определённые **внутри функции** |
| **E** | Enclosed | Переменные во **внешних (вложенных) функциях** |
| **G** | Global | Переменные, определённые **на верхнем уровне модуля** (глобальные) |
| **B** | Builtins | Встроенные имена Python (`print()`, `len()`, `open()` и т.д.) |


Пример

```python
IP_ADDR = "1.1.1.1"          # GLOBAL

def display_output(msg1):    # msg1 — LOCAL
    msg2 = "Locally defined variable"   # LOCAL
    print(f"msg1: {msg1}")
    print(f"msg2: {msg2}")
    print(f"IP Addr: {IP_ADDR}")   # обращение к GLOBAL
    print()                         # print() — BUILTIN
```

| Имя | Откуда взялось |
|-----|----------------|
| `msg1`, `msg2` | **Local** (определены внутри функции) |
| `IP_ADDR` | **Global** (определена вне функции) |
| `print` | **Builtin** (встроенная функция Python) |

Важно

- Если внутри функции есть переменная с тем же именем, что и глобальная — **локальная перекрывает глобальную** внутри функции
- Изменить глобальную переменную внутри функции можно через ключевое слово `global` (но это редко нужно и не рекомендуется)

```python
x = 10          # global

def func():
    x = 5       # local — не изменяет глобальную
    print(x)    # 5

func()
print(x)        # 10
```

📌 Итог

Порядок поиска: **Local → Enclosed → Global → Builtins**

```python
# Builtins существуют всегда
print(len("hello"))   # len() — builtin
```
