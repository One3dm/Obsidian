Функция `main()` — организация исполняемого кода


Функция `main()` — это **соглашение** (не обязательное, но рекомендуемое) для организации основного кода программы.

```python
def main():
    """Основная логика программы"""
    some_var = 42
    my_func(some_var)

def my_func(some_var):
    print(some_var)

if __name__ == "__main__":
    main()
```


Зачем нужна `main()`

1. Предотвращение «утечки» переменных

Без `main()` переменные становятся глобальными и доступны всем функциям — это плохо.

```python
# ❌ Плохо — переменная "some_var" доступна глобально
if __name__ == "__main__":
    some_var = 42
    my_func()          # my_func() зависит от глобальной переменной

def my_func():
    print(some_var)    # работает, но это плохая практика
```

С `main()` переменные **локальны** и не «просачиваются»:

```python
# ✅ Хорошо — переменная локальна внутри main()
def main():
    some_var = 42      # локальная переменная
    my_func(some_var)  # передаём явно

def my_func(some_var):
    print(some_var)

if __name__ == "__main__":
    main()
```

---

### 2. Функции становятся независимыми

Хорошая практика: функции должны быть **самодостаточными** — всё, что им нужно, передаётся через аргументы.

```python
def my_func(some_var):
    print(some_var)   # не зависит от внешних переменных
```

---

### 3. Возможность импортировать и выполнять

С `main()` можно импортировать файл и **запустить его программу** позже:

```python
import main_ex9
main_ex9.main()   # выполняем основную программу
```

Это полезно для:
- Отладки
- Повторного использования кода
- Вызова из других программ

## 📌 Итог

```python
# Стандартный шаблон
def main():
    # основная логика программы
    pass

if __name__ == "__main__":
    main()
```

| Преимущество `main()` | Описание |
|----------------------|----------|
| Локальные переменные | Не «просачиваются» в глобальную область |
| Чистые функции | Не зависят от внешнего состояния |
| Импортируемость | Можно выполнить `main()` из другого файла |
| Тестирование | Легче тестировать отдельные функции |
