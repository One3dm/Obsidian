regex101.com


Веб-сервис для создания, тестирования и отладки регулярных выражений в реальном времени.


Основные настройки

| Секция | Что делает |
|--------|-----------|
| **FLAVOR** | Выбор движка regex (Python, JavaScript, PCRE, Golang и др.) |
| **REGULAR EXPRESSION** | Поле для ввода шаблона |
| **TEST STRING** | Поле для тестового текста |
| **EXPLANATION** | Автоматическое пояснение, что делает шаблон |
| **MATCH INFORMATION** | Список найденных совпадений |
| **QUICK REFERENCE** | Шпаргалка по спецсимволам |

Пример работы

Шаблон: `r"^Configuration$"`

Ищет строку, которая **начинается и заканчивается** словом `Configuration`.

**Результат:**
- Найдено совпадение в строке `Configuration register is 0x2102` — слово `Configuration`.


Шаблон с группой: `r"^Configuration (register)$"`

- Группа `(register)` захватывает слово `register`.
- В MATCH INFORMATION появляются группы: `Group 1: register`.


Полезные возможности

| Функция | Назначение |
|---------|------------|
| `r"..."` | Сырая строка (как в Python) |
| `gm` (флаги) | `g` — global (все совпадения), `m` — multiline |
| Пояснения | Автоматически генерируются при вводе шаблона |


📌 Итог

`regex101.com` позволяет:
- Проверить шаблон до написания кода
- Увидеть пояснение каждого элемента regex
- Экспериментировать с флагами (`re.MULTILINE`, `re.DOTALL` и др.)

> [!TIP]
> Перед использованием в Python всегда выбирайте **Flavor = Python**.
