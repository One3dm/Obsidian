Изменяемые и неизменяемые объекты

Основная идея

В Python переменная — это **имя**, которое ссылается на объект в памяти.

```python
rtr1_addr = "10.250.1.1"  # Создаётся объект в памяти
gw1 = rtr1_addr           # Оба имени ссылаются на один объект
```


Неизменяемые объекты (Immutable)

**Нельзя изменить после создания.** При "изменении" создаётся новый объект.

Примеры:
- `int` (целые числа)
- `str` (строки)
- `bool` (`True`/`False`)
- `tuple` (кортежи)

```python
# Пример с int
timeout = 20
old_id = id(timeout)  # Запоминаем адрес

timeout = 10          # Создаётся новый объект
new_id = id(timeout)  # Адрес изменился

print(old_id == new_id)  # False
```

Изменяемые объекты (Mutable)

**Можно изменять после создания.** Объект остаётся тем же в памяти.

Примеры:
- `list` (списки)
- `dict` (словари)
- `set` (множества)

```python
# Пример с list
devices = ["router1", "switch1"]
old_id = id(devices)  # Запоминаем адрес

devices.append("firewall")  # Изменяем существующий объект
new_id = id(devices)        # Адрес не изменился

print(old_id == new_id)  # True
```


Ключевое различие

```python
# Неизменяемый (int)
a = 5
b = a      # b ссылается на тот же объект
a = 10     # Создаётся новый объект для a
print(b)   # 5 (b не изменился)

# Изменяемый (list)
x = [1, 2, 3]
y = x      # y ссылается на тот же объект
x.append(4) # Изменяем объект
print(y)   # [1, 2, 3, 4] (y тоже изменился!)
```



Практические последствия

Для сетевых данных
```python
# Неизменяемые — безопасны для передачи
ip_address = "192.168.1.1"
config_line = f"ip address {ip_address} 255.255.255.0"

# Изменяемые — нужна осторожность
device_list = ["router1", "switch1"]
backup_list = device_list  # Осторожно! Это не копия!

device_list.append("firewall")
print(backup_list)  # ["router1", "switch1", "firewall"] — тоже изменился!
```

Правильное копирование
```python
# Неправильно — обе переменные ссылаются на один список
devices = ["r1", "s1"]
backup = devices  # Это не копия!

# Правильно — создаём новый список
devices = ["r1", "s1"]
backup = devices.copy()  # Или backup = devices[:]

devices.append("f1")
print(devices)   # ["r1", "s1", "f1"]
print(backup)    # ["r1", "s1"] — не изменился
```


## 📌 Итог

| Тип | Примеры | Можно изменить? | При "изменении" |
|-----|---------|----------------|-----------------|
| **Неизменяемые** | `int`, `str`, `tuple`, `bool` | ❌ Нет | Создаётся новый объект |
| **Изменяемые** | `list`, `dict`, `set` | ✅ Да | Изменяется существующий объект |

**Важно:** При работе с изменяемыми объектами используйте `.copy()` для создания независимых копий.
