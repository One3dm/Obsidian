Неизменяемые объекты

Основная идея

**Неизменяемый объект нельзя изменить после создания.** При "изменении" создаётся новый объект.

Примеры:
- `int` (целые числа)
- `str` (строки)
- `bool` (`True`/`False`)
- `tuple` (кортежи)
- `None`


Как это работает
```python
# Пример с int
timeout = 20
old_id = id(timeout)  # Запоминаем адрес в памяти

timeout = 10          # Создаётся новый объект
new_id = id(timeout)  # Адрес изменился

print(old_id == new_id)  # False
```


Ключевые особенности

1. Безопасность
```python
ip_address = "192.168.1.1"
config_line = f"ip address {ip_address} 255.255.255.0"
# ip_address гарантированно не изменится
```

2. Простое присваивание
```python
a = 5
b = a      # b ссылается на тот же объект
a = 10     # Создаётся новый объект для a
print(b)   # 5 (b не изменился)
```

3. Операции создают новые объекты
```python
text = "router"
text.upper()  # Возвращает "ROUTER" — новый объект
print(text)   # "router" — оригинал не изменился
```

Практическое применение

Для сетевых данных
```python
# IP-адреса и маски — неизменяемые
ip = "192.168.1.1"
mask = "255.255.255.0"

# Можно безопасно передавать
def create_config(ip, mask):
    return f"ip address {ip} {mask}"

# Оригиналы гарантированно не изменятся
```


📌 Итог

| Тип | Пример | Можно изменить? | При "изменении" |
|-----|--------|----------------|-----------------|
| **Неизменяемые** | `int`, `str`, `tuple`, `bool` | ❌ Нет | Создаётся новый объект |

**Преимущества:** Безопасность, простота, предсказуемость.
