Именованные группы захвата

Синтаксис
```python
(?P<имя>шаблон)
```

- `?P` — указывает на именованную группу (Python-specific extension)
- `<имя>` — имя группы
- `шаблон` — то, что нужно захватить

Пример
```python
m = re.search(r"^Configuration register is (?P<configreg>\S+)$", data, flags=re.M)
```

Группа `(?P<configreg>\S+)` захватывает значение регистра конфигурации и сохраняет его под именем `configreg`.


Доступ к именованным группам

1. `m.groupdict()` — словарь всех именованных групп
```python
m.groupdict()
# {'configreg': '0x2102'}
```

2. `m.group("имя")` — значение конкретной группы
```python
m.group("configreg")
# '0x2102'
```


Преимущества

| Нумерованные группы | Именованные группы |
|---------------------|--------------------|
| `m.group(1)`, `m.group(2)` | `m.group("name")` |
| Нужно помнить номер | Не нужно помнить порядок |
| При изменении шаблона номера могут сбиться | Имена остаются теми же |


📌 Итог
```python
# Шаблон с именованной группой
pattern = r"^(?P<ip>\d+\.\d+\.\d+\.\d+)$"
m = re.search(pattern, "192.168.1.1")

if m:
    print(m.group("ip"))        # 192.168.1.1
    print(m.groupdict())        # {'ip': '192.168.1.1'}
```
