**Базовые примеры регулярных выражений**

Метод `re.search()`

`re.search(pattern, string, flags=0)` — основной метод для поиска **первого** совпадения шаблона в строке.

| Аргумент | Что значит |
|----------|------------|
| `pattern` | Регулярное выражение (шаблон) |
| `string` | Строка, в которой ищем |
| `flags` | Флаги (например, `re.MULTILINE`, `re.DOTALL`) |

**Возвращает:**
- **Match object** — если шаблон найден.
- **`None`** — если ничего не найдено.


## Пример данных (из `show version`)

```python
line1 = "Cisco IOS XE Software, Version 16.08.01"
line2 = "Cisco IOS Software [Fuji], ISR Software (ARMv8EB_LINUX_IOSD-UNIVERSALK9_IAS-M), Version 16.8.1, RELEASE SOFTWARE (fc3)"
```


Поиск простых последовательностей

| Шаблон | Что ищет | Пример на `line2` |
|--------|----------|-------------------|
| `"."` (точка) | Любой 1 символ | `'C'` |
| `".."` (две точки) | Любые 2 символа | `'Ci'` |
| `"..."` (три точки) | Любые 3 символа | `'Cis'` |
| `".*"` | **0 или более** любых символов (вся строка) | вся `line2` |
| `".+"` | **1 или более** любых символов | вся `line2` (начиная с 1-го) |
| `".*?"` | **0 или более**, но **лениво** (минимально) | `''` (пустая строка) |
| `".+?"` | **1 или более**, но **лениво** | `'C'` (только первый символ) |

> [!IMPORTANT]
> `.*` (жадный) захватывает **всё**. `.*?` (ленивый) захватывает **минимально возможное**.


Match object и `.group()`
Если `re.search()` нашёл совпадение, он возвращает **объект Match**.

```python
m = re.search(".*", line2)
print(m.group(0))   # вся строка целиком
```

- `.group(0)` — весь найденный текст.
- Если в шаблоне есть **группы** `()`, то `.group(1)`, `.group(2)` и т.д. будут возвращать содержимое этих групп.

Пример: поиск `"Cisco"` + пробелы + `"Fuji"`

```python
# \s — любой пробельный символ (пробел, табуляция, \n)
# .* - любые символы между "Cisco" и "Fuji" (нужно, если текст длинный)

m = re.search(r"Cisco\s.*Fuji", line2)
print(m.group())   # 'Cisco IOS Software [Fuji'

# Более простой случай — когда слова идут подряд
alt_line = "Cisco Fuji"
m = re.search(r"Cisco\sFuji", alt_line)
print(m.group())   # 'Cisco Fuji'
```

- `\s` — может обозначать пробел, табуляцию, перевод строки.
- `.*` — любые символы между ними (сколько угодно, включая ноль).


📌 Итог (практические выводы)

| Что хотим сделать | Шаблон |
|-------------------|--------|
| Найти первое слово | `"^\w+"` |
| Найти первую цифру/цифры | `"\d+"` |
| Найти всё между `"Cisco"` и `"Fuji"` | `"Cisco.*Fuji"` |
| Найти всё до запятой (не включая её) | `".*?,"` |
| Получить объект совпадения | `m = re.search(шаблон, данные)` |
| Взять найденный текст | `m.group()` или `m.group(0)` |
