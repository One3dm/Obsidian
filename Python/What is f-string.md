
**Что такое буква `f` перед строкой в Python?**

Простое объяснение

Буква `f` перед строкой превращает её в **f-строку** (formatted string) — специальную строку, где содержимое внутри фигурных скобок `{}` выполняется как код Python.

### Без `f` vs С `f`

```python
# БЕЗ f - обычная строка
name = "Router1"
text = "Device: {name}"
print(text)  # Вывод: Device: {name}

# С f - f-строка (значение подставляется)
name = "Router1"
text = f"Device: {name}"
print(text)  # Вывод: Device: Router1
```

## Почему `f` так важен?

Без `f` фигурные скобки `{}` — это просто текст.
С `f` фигурные скобки `{}` — это "окна", куда Python подставляет значения.

```python
# Аналогия: Шаблон документа
template = "IP: {ip_address}, Mask: {subnet_mask}"  # Шаблон
ip_address = "192.168.1.1"
subnet_mask = "255.255.255.0"

# Без f - остаётся шаблоном
print(template)  # IP: {ip_address}, Mask: {subnet_mask}

# С f - заполняется значениями
print(f"IP: {ip_address}, Mask: {subnet_mask}")
# IP: 192.168.1.1, Mask: 255.255.255.0
```

## Что можно делать внутри `{}`?

```python
# 1. Подставлять переменные
device = "SW-01"
print(f"Hostname: {device}")  # Hostname: SW-01

# 2. Выполнять выражения
print(f"Сумма: {5 + 3}")  # Сумма: 8

# 3. Вызывать методы
ip = "192.168.1.1"
print(f"IP uppercase: {ip.upper()}")  # IP uppercase: 192.168.1.1

# 4. Использовать функции
def get_vlan_name(vlan_id):
    return f"VLAN{vlan_id:04d}"
    
print(f"VLAN: {get_vlan_name(10)}")  # VLAN: VLAN0010
```

## Частая ошибка новичков

```python
# ❌ ЗАБЫЛИ поставить f
ip = "10.0.0.1"
command = "ping {ip}"  # Забыли f!
print(command)  # ping {ip} - не то что хотели

# ✅ НЕ ЗАБЫЛИ поставить f
ip = "10.0.0.1"
command = f"ping {ip}"  # Помнили про f!
print(command)  # ping 10.0.0.1 - правильно!
```

## Правило на всю жизнь

**Видишь фигурные скобки `{}` в строке с переменными → поставь `f` перед кавычками!**

```python
# Правило применения:
переменная = "значение"

# Шаг 1: Пишем строку с {}
текст = "Текст {переменная}"

# Шаг 2: Добавляем f перед кавычками
текст = f"Текст {переменная}"

# Шаг 3: Получаем нужный результат
print(текст)  # Текст значение
```

## Другие префиксы строк

```python
# f - formatted (форматированная) - подставляет значения
text = f"Value: {x}"

# r - raw (сырая) - игнорирует спецсимволы
path = r"C:\Users\Name"  # \U и \N не считаются спецсимволами

# b - bytes (байтовая) - строка из байтов
data = b"hello"

# u - unicode (устарело в Python 3)
text = u"текст"  # В Python 3 все строки unicode по умолчанию
```

## 📌 Итог

| Ситуация | Что писать | Пример |
|----------|------------|--------|
| **Хочу подставить переменную** | `f"текст {var}"` | `f"IP: {ip_address}"` |
| **Просто текст с фигурными скобками** | `"текст {}"` (без f) | `"Шаблон: {}"` |
| **Путь с обратными слэшами** | `r"путь"` | `r"C:\Windows\System32"` |
| **Работа с байтами** | `b"данные"` | `b"\x48\x65\x6c\x6c\x6f"` |

**Золотое правило:** Если в строке есть `{}` и ты хочешь подставить туда значения переменных — **всегда начинай строку с `f`**.
