Импорт библиотек (Importing Libraries)

Что происходит при `import`

```python
import re
```

Python выполняет следующие шаги:


Шаг 1: Поиск библиотеки

Python ищет библиотеку с помощью `sys.path` (список директорий, где Python ищет модули).

```python
(Pdb) re.__file__
'/usr/local/lib/python3.11/re/__init__.py'
```


Шаг 2: Загрузка файла

После того как библиотека найдена, Python загружает её содержимое **построчно (line-by-line)**, сверху вниз.


Шаг 3: Рекурсивный импорт зависимостей

Импортируемая библиотека может содержать свои собственные импорты. Python рекурсивно загружает все зависимости (включая зависимости зависимостей).

```python
# re/__init__.py
import enum
from . import _compiler, _parser
import functools

# enum.py
import sys
import builtins as bltns
from types import MappingProxyType, DynamicClassAttribute
from operator import or_ as _or_
from functools import reduce
```


Шаг 4: Определение имён

Библиотека определяет **классы**, **функции** и **константы**, которые становятся доступными в вашем коде.


📌 Ключевые моменты

1. **`import re`** заставляет Python найти библиотеку и загрузить всё её содержимое построчно.
2. В процессе происходит **рекурсивная загрузка** всех зависимостей.
3. Библиотеки определяют **переиспользуемые вещи**: классы, функции, константы.

```python
# Простой импорт
import re

# После импорта можно использовать
pattern = re.compile(r"\d+")
```
