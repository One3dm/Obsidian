**Числа в Python**

Типы чисел

| Тип | Описание | Пример | Когда использовать |
|-----|----------|--------|-------------------|
| `int` | Целые числа | `22`, `-5`, `1000`, `0b1010` | Счётчики, порты, версии, индексы |
| `float` | Числа с плавающей точкой | `3.3`, `-0.5`, `7.75`, `1.0e-3` | Проценты, метрики, измерения |
| `complex` | Комплексные числа | `3+4j`, `2j` | Специальные вычисления (редко в сетях) |

```python
my_var = 22
type(my_var)    # <class 'int'>

my_var = 3.3
type(my_var)    # <class 'float'>

# Проверка типа
isinstance(42, int)      # True
isinstance(3.14, float)  # True
```

Представления чисел:
```python
# Разные системы счисления
decimal = 42          # Десятичная
binary = 0b101010     # Двоичная (42)
octal = 0o52          # Восьмеричная (42)
hexadecimal = 0x2A    # Шестнадцатеричная (42)

# Научная нотация
large = 1.5e6         # 1.5 × 10⁶ = 1500000
small = 2.5e-3        # 0.0025
```

Стандартные математические операции

| Оператор | Значение | Пример | Результат |
|----------|----------|--------|-----------|
| `+` | Сложение | `17 + 22` | `39` |
| `-` | Вычитание | `22 - 7` | `15` |
| `*` | Умножение | `3 * 4` | `12` |
| `/` | Деление (всегда возвращает float) | `4 / 7` | `0.5714285714285714` |
| `//` | Целочисленное деление | `7 // 2` | `3` |
| `%` | Остаток от деления | `7 % 2` | `1` |
| `**` | Возведение в степень | `2 ** 3` | `8` |

Практические примеры для сетевых расчётов:
```python
# Расчёт пропускной способности
bandwidth_mbps = 1000

```

Особенности деления
```python
# Обычное деление (всегда float)
print(4 / 2)    # 2.0 (даже если делится нацело)
print(5 / 2)    # 2.5

# Целочисленное деление (отбрасывает дробную часть)
print(7 // 2)   # 3
print(-7 // 2)  # -4 (округление в меньшую сторону!)

# Остаток от деления
print(7 % 2)    # 1
print(8 % 3)    # 2
print(10 % 5)   # 0
```

Полезный трюк: проверка делимости
```python
# Проверка, что число кратно 8 (для выравнивания)
mtu = 1500
if mtu % 8 == 0:
    print("MTU корректно выровнено")
else:
    print("MTU должно быть кратно 8")
```

Округление чисел
```python
my_var = 4 / 3    # 1.3333333333333333
round(my_var, 2)  # 1.33
round(my_var, 0)  # 1.0
round(my_var)     # 1 (без второго аргумента → до целого)
```

Разные способы округления:
```python
import math

value = 3.75

# round() - банковское округление (к ближайшему чётному)
round(3.5)   # 4
round(4.5)   # 4 (к чётному!)

# math.floor() - вниз
math.floor(3.75)  # 3

# math.ceil() - вверх  
math.ceil(3.25)   # 4

# math.trunc() - отбрасывание дробной части
math.trunc(3.75)  # 3
```

Практическое использование:
```python
# Округление метрик сети
packet_loss = 0.034567
print(f"Потери: {packet_loss:.2%}")      # 3.46%
print(f"Потери: {round(packet_loss * 100, 2)}%")  # 3.46%

# Округление до ближайшего кратного
def round_to_multiple(value, multiple):
    return round(value / multiple) * multiple

mtu = 1497
standard_mtu = round_to_multiple(mtu, 8)  # 1496
```

Инкремент и составные операторы
```python
i = 0
i = i + 1    # i = 1
i += 1       # i = 2 (сокращённая запись)
i += 1       # i = 3
```

Все составные операторы:
```python
counter = 10

counter += 5   # 15 (counter = counter + 5)
counter -= 3   # 12 (counter = counter - 3)
counter *= 2   # 24 (counter = counter * 2)
counter /= 4   # 6.0 (counter = counter / 4)
counter //= 2  # 3.0 (counter = counter // 2)
counter %= 2   # 1.0 (counter = counter % 2)
counter **= 3  # 1.0 (counter = counter ** 3)
```

 Практическое использование в сетях:
```python
# Подсчёт статистики
total_packets = 0
total_bytes = 0

# В цикле обработки пакетов
for packet in packets:
    total_packets += 1
    total_bytes += packet.size

print(f"Пакетов: {total_packets}, Байт: {total_bytes}")

# Наращивание таймаутов
timeout = 1
max_retries = 5

for attempt in range(max_retries):
    print(f"Попытка {attempt + 1}, таймаут: {timeout}с")
    timeout *= 2  # Экспоненциальная backoff: 1, 2, 4, 8, 16
```

Преобразование типов
```python
# Явное преобразование
int("42")        # 42
float("3.14")    # 3.14
str(100)         # "100"

# Автоматическое преобразование в операциях

# Осторожно с преобразованием строк

```

## Особенности float (плавающей точки)

```python
# Точность float ограничена
0.1 + 0.2  # 0.30000000000000004 (не точно 0.3!)

# Сравнение float
x = 0.1 + 0.2
y = 0.3
x == y  # False (осторожно!)

# Правильное сравнение float
abs(x - y) < 1e-10  # True (сравнение с допуском)

# Модуль decimal для точных вычислений
from decimal import Decimal
Decimal('0.1') + Decimal('0.2')  # Decimal('0.3')
```

## 📌 Итог

### Основные операции:

| Что делаем | Как | Пример |
|------------|-----|--------|
| Целые числа | `int` | `port = 22` |
| Дробные числа | `float` | `loss = 0.05` |
| Деление | `/` всегда возвращает `float` | `7 / 2 → 3.5` |
| Целочисленное деление | `//` | `7 // 2 → 3` |
| Остаток от деления | `%` | `7 % 2 → 1` |
| Степень | `**` | `2 ** 3 → 8` |
| Округление | `round(число, знаки)` | `round(3.14159, 2) → 3.14` |
| Увеличение на 1 | `i += 1` | Счётчики, индексы |

### Практические советы для сетевого инженера:

1. **Используйте `int` для** номеров портов, VLAN, версий, счётчиков
2. **Используйте `float` для** процентов, метрик, измерений
3. **Проверяйте делимость** с помощью `%` (кратность 8 для MTU и т.д.)
4. **Осторожно с float сравнением** — используйте допуск
5. **Преобразуйте ввод пользователя** в числа явно: `int(input(...))`
6. **Используйте составные операторы** для наращивания счётчиков

### Быстрые формулы для сетей:

```python
# Количество хостов в подсети: 2^(32 - mask) - 2
hosts = 2 ** (32 - 24) - 2  # /24 → 254 хоста

# Проверка валидности порта
def is_valid_port(port):
    return isinstance(port, int) and 1 <= port <= 65535

# Округление до стандартных значений
def round_to_standard_mtu(mtu):
    # Стандартные MTU: 1500, 1492, 9000
    standards = [1500, 1492, 9000]
    return min(standards, key=lambda x: abs(x - mtu))
```
