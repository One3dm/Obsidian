**Генераторные выражения (Generator Expressions)**

Проблема: списки могут быть слишком большими
```python
my_list = list(range(100_000_000))   # ❌ MemoryError
```

Список из 100 миллионов чисел занимает **очень много памяти**. Python может не справиться.


Что такое генератор

**Генератор** — это функция/выражение, которое выдаёт значения **по одному**, не храня их все в памяти.

Вместо того чтобы выделить место под все элементы, генератор «знает», как получить следующий элемент из предыдущего.
```python
def gen(n):
    i = 0
    while i < n:
        yield i   # возвращает значение, но запоминает состояние
        i += 1

for val in gen(4):
    print(val)   # 0, 1, 2, 3
```

`yield` — ключевое слово, которое делает функцию генератором.


Генераторные выражения (краткий синтаксис)

Выглядят как **list comprehensions**, но с круглыми скобками `()` вместо квадратных `[]`.

```python
my_generator = (x**2 for x in range(10))

type(my_generator)   # generator
```

Использовать можно в цикле `for`:

```python
for val in my_generator:
    print(val)        # 0, 1, 4, 9, 16, 25, 36, 49, 64, 81
```


Преимущества: экономия памяти

Генератор **не вычисляет все значения сразу**, а только по одному при каждой итерации.

```python
# Список — требует память сразу
my_list = [x**2 for x in range(10_000_000)]   # Может упасть

# Генератор — почти не потребляет память
my_gen = (x**2 for x in range(10_000_000))    # ✅ OK
for val in my_gen:
    # обрабатываем по одному значению
    if val > 1000:
        break
```



Генераторы с несколькими циклами
```python
base_addr = "10.77"

ip_generator = (
    f"{base_addr}.{x}.{y}"
    for x in range(10, 13)
    for y in range(2, 11)
)

for ip_addr in ip_generator:
    print(ip_addr)
    break   # 10.77.10.2
```


Условия (`if`) в генераторных выражениях

```python
ip_generator = (
    f"10.77.{x}.{y}"
    for x in range(10, 13)
    for y in range(2, 11)
    if x == y
)
```



⚠️ «Подводный камень»: генераторы не сбрасываются

Генератор **запоминает своё состояние** после использования. Повторно его перебрать нельзя.

```python
gen = (x**2 for x in range(3))

for val in gen:
    print(val)        # 0, 1, 4

for val in gen:
    print(val)        # ничего не выведет (генератор уже исчерпан)
```

Нужно создать **новый** генератор для повторного обхода.


Сравнение: list comprehension vs generator expression

| Характеристика | List comprehension | Generator expression |
|----------------|--------------------|-----------------------|
| Синтаксис | `[выражение for ...]` | `(выражение for ...)` |
| Результат | `list` | `generator` |
| Память | Все элементы сразу | Один элемент за раз |
| Повторное использование | ✅ можно много раз | ❌ только один раз |
| Когда использовать | Небольшие данные, нужны все элементы сразу | Большие данные, потоковая обработка |


📌 Итог

```python
# Генераторное выражение
ip_gen = (f"10.77.{x}.{y}" for x in range(10) for y in range(5))

# Экономит память при больших диапазонах
big_gen = (x**2 for x in range(100_000_000))

# Можно использовать в циклах
for val in big_gen:
    if val > 1000:
        break

# Генератор не сбрасывается — если закончился, создайте новый
```

> [!TIP]
>- **Маленькие данные** — list comprehension удобнее
>- **Большие данные** — generator expression эффективнее по памяти
>- **Нужен повторный обход** — используйте list comprehension или создавайте генератор заново
