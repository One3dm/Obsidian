**Генераторы словарей**

**Генератор словаря** — компактный способ динамического создания словаря с помощью цикла `for`.

Синтаксис похож на **генераторы множеств** (фигурные скобки), но вместо одного значения указывается **пара `ключ: значение`**.

```python
{ключ: значение for переменная in итерируемый_объект}
```


Базовый пример
```python
{f"rtr{x}": f"10.220.17.{x+20}" for x in range(1, 5)}
```

**Результат:**

```python
{
    "rtr1": "10.220.17.21",
    "rtr2": "10.220.17.22",
    "rtr3": "10.220.17.23",
    "rtr4": "10.220.17.24"
}
```


Перестановка ключа и значения

Иногда нужно поменять местами ключи и значения исходного словаря.

```python
routers = {
    "rtr1": "192.168.150.1",
    "rtr2": "192.168.151.1",
    "rtr3": "192.168.152.1"
}

ip_addr = {v: k for k, v in routers.items()}
```

**Результат:**

```python
{
    "192.168.150.1": "rtr1",
    "192.168.151.1": "rtr2",
    "192.168.152.1": "rtr3"
}
```

> [!WARNING]
> **Условия для перестановки:**
> - Значения должны быть **уникальными** (иначе произойдёт коллизия)
> - Значения должны быть **неизменяемыми** (строки, числа, кортежи)


Что происходит с дубликатами

Если при перестановке встречаются одинаковые значения (будущие ключи), **последний встреченный** остаётся в словаре.

```python
routers = {
    "rtr1": "192.168.150.1",
    "rtr2": "192.168.151.1",
    "rtr3": "192.168.152.1",
    "dup-rtr": "192.168.152.1"      # дубликат значения
}

ip_addr = {v: k for k, v in routers.items()}
```

**Результат:**

```python
{
    "192.168.150.1": "rtr1",
    "192.168.151.1": "rtr2",
    "192.168.152.1": "dup-rtr"      # последнее значение перезаписало предыдущее
}
```


Сравнение с другими генераторами

| Тип | Синтаксис | Результат | Пример |
|-----|-----------|-----------|--------|
| List comprehension | `[выражение for ...]` | `list` | `[x**2 for x in range(5)]` |
| Set comprehension | `{выражение for ...}` | `set` | `{x**2 for x in range(5)}` |
| Dictionary comprehension | `{ключ: значение for ...}` | `dict` | `{f"key{x}": x**2 for x in range(5)}` |


📌 Итог

```python
# Базовая форма
{key_expr: value_expr for item in iterable}

# С условием
{key_expr: value_expr for item in iterable if condition}

# Перестановка ключей и значений
{value: key for key, value in original.items()}
```

> [!TIP]
> Генераторы словарей делают код компактнее, особенно при создании словарей из существующих коллекций или при преобразовании одного словаря в другой.
