Библиотеки и окружение — обзор

Вопросы, которые нужно решить

| Вопрос | Ответ |
|--------|-------|
| Как найти библиотеки? | Google, PyPI, GitHub |
| Как устанавливать библиотеки? | PIP |
| Как использовать библиотеки в коде? | `import foo`, `from foo import bar` |
| Где Python ищет библиотеки? | `sys.path`, `$PYTHONPATH` |
| Как управлять окружениями? | Виртуальные окружения, poetry, pipenv, pyenv |

Откуда берутся библиотеки

1. **Встроенные в Python** — уже есть в стандартной библиотеке
   - `re`, `getpass`, `sys`, `os`, `math` и др.

2. **Из PyPI** — Python Package Index (pypi.org)
   - `rich`, `netmiko`, `requests` и др.

3. **Созданные самостоятельно** — ваши модули или модули команды

4. **Из репозиториев (GitHub/GitLab)** — напрямую из VCS


📌 Итог

```python
# Встроенная библиотека (уже есть)
import re
import getpass

# Библиотека из PyPI (нужно установить)
# pip install rich
import rich
```
