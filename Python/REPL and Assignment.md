**Переменные и присваивание в Python**

**REPL** — интерактивная оболочка Python, где код выполняется построчно.

**Запуск REPL:**
```bash
python          # стандартная оболочка
python -m IPython   # IPython (с подсветкой и удобствами)
```

**Присваивание переменных**

```python
my_var = 22
my_ip_addr = "192.168.88.7"
sf_dc_svr9 = "svr9a.lasthop.io"
global_delay_factor = 4
```

**Правила именования переменных**

| ✅ Можно | ❌ Нельзя |
|---------|-----------|
| Буквы (a-z, A-Z) | Начинать с цифры |
| Цифры (не в начале) | Пробелы |
| Нижнее подчёркивание `_` | Спецсимволы (@, #, $, %) |
**Примеры:**

```python
# ✅ Правильно
my_var = 22
my_var9 = "string"
_my_var72 = "private"
my_ip_address = "10.220.107.99"

# ❌ Ошибка
9my_var = "whatever"    # SyntaxError: invalid decimal literal
```

**Конвенция: snake_case**

В Python принято использовать **snake_case** для переменных:

```python
# snake_case — все буквы маленькие, слова через _
my_ip_address = "192.168.88.7"
sf_gw1 = "172.31.255.1/24"
delay_factor = 4
```

**Специальные переменные**

```python
_           # в REPL хранит последний результат
__name__    # имя текущего модуля (служебная)
```

---

## Проверка типа переменной

```python
my_var = 22
type(my_var)    # <class 'int'>

my_var9 = "string"
type(my_var9)   # <class 'str'>
```

---

## 📌 Итог

- Переменная = имя, которое ссылается на значение
- Имя должно начинаться с буквы или `_`
- Нельзя начинать с цифры
- Используем `snake_case`
- REPL позволяет тестировать код построчно
