**Переменные и присваивание в Python**

**REPL** (Read-Eval-Print Loop) — интерактивная оболочка Python, где код выполняется построчно. *Идеально для быстрого тестирования идей и изучения языка.*

**Запуск REPL:**
```bash
python          # стандартная оболочка
python -m IPython   # IPython (с подсветкой и удобствами)
```

**Присваивание переменных**

```python
my_var = 22
my_ip_addr = "192.168.88.7"
sf_dc_svr9 = "svr9a.lasthop.io"
global_delay_factor = 4
```

## Множественное присваивание

```python
# Присвоение нескольких значений
ip, mask = "10.0.0.1", "255.255.255.0"

# Обмен значений (без временной переменной)
a = 5
b = 10
a, b = b, a  # теперь a=10, b=5
```

**Правила именования переменных**

| ✅ Можно                         | ❌ Нельзя                                     |
| ------------------------------- | -------------------------------------------- |
| Буквы (a-z, A-Z)                | Начинать с цифры                             |
| Цифры (не в начале)             | Пробелы                                      |
| Нижнее подчёркивание `_`        | Спецсимволы (@, #, $, %)                     |
| Кириллицу (но не рекомендуется) | Ключевые слова Python (`if`, `for`, `class`) |
**Примеры:**

```python
# ✅ Правильно
my_var = 22
my_var9 = "string"
_my_var72 = "private"
my_ip_address = "10.220.107.99"

# ❌ Ошибка
9my_var = "whatever"    # SyntaxError: invalid decimal literal

# ❌ Ошибка — использование ключевого слова
class = "MyClass"  # SyntaxError: invalid syntax
if = 10            # SyntaxError: invalid syntax
```

**Конвенция: snake_case**

В Python принято использовать **snake_case** для переменных:

```python
# snake_case — все буквы маленькие, слова через _
my_ip_address = "192.168.88.7"
sf_gw1 = "172.31.255.1/24"
delay_factor = 4
```

**Специальные переменные**

```python
_           # в REPL хранит последний результат
__name__    # имя текущего модуля (служебная)
```

**Проверка типа переменной**

```python
my_var = 22
type(my_var)    # <class 'int'>

my_var9 = "string"
type(my_var9)   # <class 'str'>

# Практическое использование type() 
value = "192.168.1.1" 
if type(value) == str: 
print("Это строка - можно использовать как IP-адрес")
```


📌 Итог
- Переменная = имя, которое ссылается на значение
- Имя должно начинаться с буквы или `_`
- Нельзя начинать с цифры
- Используем `snake_case`
- REPL позволяет тестировать код построчно
- Python использует **динамическую типизацию** — тип переменной определяется в момент присваивания 
- Одна переменная может менять тип в ходе программы: ```python x = 10 # x - int x = "text" # теперь x - str
