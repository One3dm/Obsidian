Характеристики Python

Отступы имеют значение (Indentation matters)

В Python **отступы определяют блоки кода**. В других языках (C, Java) используют фигурные скобки `{}`, в Python — пробелы.

```python
# Правильно — отступ показывает блок кода
if x > 5:
    print("x больше 5")
    print("это тоже внутри if")
print("это вне if")
```

**Ошибка — неправильный отступ:**
```python
if x > 5:
print("Hello")   # IndentationError: expected an indented block
```

Используйте пробелы, не табуляции (Use spaces, not tabs)

- PEP 8 рекомендует **4 пробела** для одного уровня отступа
- Смешивать пробелы и табуляции — **плохая практика**, приводит к ошибкам

> [!TIP]
> Настройте редактор так, чтобы клавиша Tab вставляла 4 пробела.

## 3. Python-программисты щепетильны (Python programmers are particular)

- Сообщество Python строго следит за стилем кода
- Читаемость кода — одна из главных ценностей Python

---

## PEP 8 — руководство по стилю

Основные правила:
- 4 пробела на уровень отступа
- Максимальная длина строки — 79 символов
- Пустые строки для разделения функций и классов
- Пробелы вокруг операторов (`a = b`, не `a=b`)

📌 **Итог**

| Правило | Почему важно |
|---------|-------------|
| Отступы определяют блоки кода | Без них код не работает |
| 4 пробела (не табы) | Единый стандарт |
| Следовать PEP 8 | Код читают другие (и вы сами через месяц) |
