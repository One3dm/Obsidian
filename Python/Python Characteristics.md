**Характеристики Python**

**Отступы имеют значение (Indentation matters)**

В Python **отступы определяют блоки кода**. В других языках (C, Java) используют фигурные скобки `{}`, в Python — пробелы.
```python
# Правильно — отступ показывает блок кода
if x > 5:
    print("x больше 5")
    print("это тоже внутри if")
print("это вне if")
```

**Ошибка — неправильный отступ:**
```python
if x > 5:
print("Hello")   # IndentationError: expected an indented block
```

**Вложенные блоки — несколько уровней отступов:**
```python
if device_status == "up":
    print("Устройство активно")
    if ping_successful:
        print("Пинг проходит")
        print("Можно продолжать настройку")
    print("Проверка завершена")
```

**Используйте пробелы, не табуляции (Use spaces, not tabs)**
- PEP 8 рекомендует **4 пробела** для одного уровня отступа
- Смешивать пробелы и табуляции — **плохая практика**, приводит к ошибкам

> [!TIP]
> Настройте редактор так, чтобы клавиша Tab вставляла 4 пробела.

**Python-программисты щепетильны (Python programmers are particular)**
- Сообщество Python строго следит за стилем кода
- Читаемость кода — одна из главных ценностей Python

**PEP 8 — руководство по стилю**
Основные правила:
- 4 пробела на уровень отступа
- Максимальная длина строки — 79 символов
- Пустые строки для разделения функций и классов
- Пробелы вокруг операторов (`a = b`, не `a=b`)

**Максимальная длина строки — 79 символов**
*Особенно важно для длинных строк с IP-адресами, командами CLI:*
```python
# Слишком длинно (плохо)
device_connection_string = "ssh://admin:password@192.168.1.1:22"

# Лучше использовать перенос
device_connection_string = (
    "ssh://admin:password@"
    "192.168.1.1:22"
)
```

Инструменты для проверки стиля
- **black** — автоматический форматировщик кода
- **flake8** — проверка на соответствие PEP 8
- **autopep8** — автоматическое исправление стиля

```bash
# Установка
pip install black flake8 autopep8

# Автоформатирование файла
black my_script.py
```

📌 **Итог**

| Правило | Почему важно | Практический совет |
|---------|-------------|-------------------|
| Отступы определяют блоки кода | Без них код не работает | **Всегда используйте 4 пробела** |
| 4 пробела (не табы) | Единый стандарт | Настройте редактор на "Tab = 4 пробела" |
| Следовать PEP 8 | Код читают другие (и вы сами через месяц) | Используйте `black` для автоформатирования |
