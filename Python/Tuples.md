Кортежи

Что такое кортеж

**Кортеж (tuple)** — **неизменяемая** версия списка. Создаётся с помощью круглых скобок `()`.

```python
my_tuple = (1, "hello", 22, None, 2.7)
type(my_tuple)    # tuple
```

Основные характеристики

Неизменяемость
```python
my_tuple[2] = 44   # ❌ TypeError
my_tuple.append(88) # ❌ AttributeError
```

Доступ к элементам
```python
my_tuple[0]    # 1
my_tuple[-1]   # 2.7
```

Важные особенности

Создание кортежа
```python
# Стандартный способ
ip_addresses = ("10.1.1.1", "10.1.1.2")

# Без скобок (тоже работает)
ip_addresses = "10.1.1.1", "10.1.1.2"

# Один элемент (нужна запятая!)
single = (42,)    # кортеж
not_a_tuple = (42) # int
```

Методы кортежа
```python
my_tuple.count(22)    # Сколько раз встречается 22
my_tuple.index("hello") # Позиция элемента "hello"
```


Практическое применение

Константы и настройки
```python
# Неизменяемые настройки
DEFAULT_PORTS = (22, 80, 443, 8080)
PROTOCOLS = ("TCP", "UDP", "ICMP")

# Проверка
if port in DEFAULT_PORTS:
    print(f"Port {port} is allowed")
```

Возврат нескольких значений из функции
```python
def get_device_info():
    """Возвращает информацию об устройстве"""
    name = "Router1"
    ip = "192.168.1.1"
    uptime = 365
    return name, ip, uptime  # Автоматически создаётся кортеж

# Использование
device_info = get_device_info()
print(device_info)  # ("Router1", "192.168.1.1", 365)

# Распаковка
name, ip, uptime = get_device_info()
```

Ключи в словарях
```python
# Кортеж как ключ (список не может быть ключом)
device_interfaces = {
    ("router1", "GigabitEthernet0/1"): "192.168.1.1",
    ("router1", "GigabitEthernet0/2"): "192.168.1.2",
    ("switch1", "Vlan10"): "192.168.10.1"
}

# Доступ
ip = device_interfaces[("router1", "GigabitEthernet0/1")]
```

Конфигурация интерфейсов
```python
# Неизменяемая конфигурация интерфейса
interface_config = (
    "GigabitEthernet0/1",
    "192.168.1.1",
    "255.255.255.0",
    "Uplink to core"
)

# Распаковка
interface, ip, mask, description = interface_config
print(f"Configuring {interface}: {ip}/{mask}")
```

Сравнение: list vs tuple

| Характеристика | `list` | `tuple` |
|---------------|--------|---------|
| Изменяемость | ✅ да | ❌ нет |
| Синтаксис | `[1, 2, 3]` | `(1, 2, 3)` |
| Использование как ключ словаря | ❌ нельзя | ✅ можно |
| Методы | `.append()`, `.pop()` и др. | только `.count()` и `.index()` |

📌 Итог

| Действие | Код |
|----------|-----|
| Создать кортеж | `t = (1, 2, 3)` |
| Создать кортеж из одного элемента | `t = (42,)` |
| Получить элемент | `t[0]` |
| Проверить вхождение | `22 in t` |
| Подсчитать элементы | `t.count(22)` |
| Найти позицию | `t.index("hello")` |

**Когда использовать:**
- ✅ Данные не должны меняться
- ✅ Нужен ключ для словаря  
- ✅ Возврат нескольких значений из функции
- ❌ Если нужно добавлять/удалять элементы
