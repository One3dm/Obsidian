**Введение в регулярные выражения (regex)**

Зачем нужны регулярные выражения

**Проблема:** сетевые устройства возвращают нам **строки** (show version, show ip arp, конфиги). Нужно уметь **извлекать** из этих строк нужную информацию: IP-адреса, MAC-адреса, серийные номера, версии ПО и т.д.

**Решение:** регулярные выражения — это **специальный язык** для создания шаблонов поиска в тексте.

> [!WARNING]
> Сложные регулярные выражения могут быть **очень запутанными**. Их называют «дорогой в ад» из-за сложности чтения и отладки.


Простейший случай: литеральные строки
Если нужно найти **конкретную подстроку**, можно использовать `re.search()` с простой строкой.

Импорт модуля `re`
```python
import re
```

### Пример: поиск "Configuration register"

```python
data = """... какой-то длинный текст ..."""

match = re.search("Configuration register", data)

print(match)
# <re.Match object; span=(135, 157), match='Configuration register'>
```

### Что такое `match`?

- Если **есть совпадение** — match содержит объект с информацией о найденном.
- Если **нет совпадения** — match будет `None`.

### Доступ к найденному тексту

```python
if match:
    print(match.group(0))   # 'Configuration register'
```

`.group(0)` — возвращает **весь** найденный текст (все, что совпало с шаблоном).

---

## Простейший пример с условием

```python
import re

match = re.search("Configuration register", data)

if match:
    print("found")
else:
    print("not found")
```

## 📌 Итог

| Что делаем | Как |
|------------|-----|
| Импорт модуля | `import re` |
| Поиск подстроки | `re.search("текст", data)` |
| Проверка успешности | `if match:` |
| Получить найденное | `match.group(0)` |

> [!NOTE]
> Пока это не regex в полном смысле, а просто поиск подстроки. Магия начинается со **специальными символами**.
