PyPI — Python Package Index

**PyPI** (Python Package Index) — это официальный репозиторий программного обеспечения для Python. Здесь публикуются библиотеки, которые можно установить через `pip`.

Сайт: [pypi.org](https://pypi.org/)


Статистика PyPI

- **474 896** проектов
- **4 767 994** релизов
- **8 880 900** файлов
- **731 374** пользователей

Поиск библиотек

На PyPI можно искать библиотеки по ключевым словам, фильтровать по категориям:

- Framework
- Topic
- Development Status
- License
- Programming Language
- Operating System

Пример: поиск `netmiko`

Результат поиска показывает:
- Название и версию
- Краткое описание
- Дату последнего релиза
